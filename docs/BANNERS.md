# 쿠팡 배너 규격

쿠팡 파트너스 배너는 `config/affiliate-banners.json`에서 위치별로 설정합니다. PC 본문에는 사용자가 다시 저장해 제공한 ID `1038394`, 모바일에는 기존 ID `1038387`, 오른쪽 세로 배너에는 추가로 제공한 ID `1038395`를 연결했습니다. 추적 코드는 모두 `AF1976226`입니다. 배너 유형은 사용자 화면에서 고객 관심 기반 추천으로 설정하며, 모든 글에 공통 템플릿을 적용하므로 원고마다 배너를 만들 필요가 없습니다. 서로 다른 PC·모바일 ID는 `widget`과 `mobileWidget`으로 각각 보존합니다.

홈에서는 최신 글 다섯 개를 읽은 뒤 가로 배너 하나를 표시합니다. 글이 1~4개면 글 목록 끝에 표시하고, 글이 없거나 검색·카테고리로 목록을 필터링한 상태에서는 홈 배너를 표시하지 않습니다. 홈의 상단 광고 띠와 세로 광고는 제거했습니다. 글 페이지에서는 중간 배너와 오른쪽 세로 배너를 사용합니다. 본문은 공간이 충분할 때 728×90, 좁은 화면에서는 300×250을 불러옵니다. 배너 제목과 수수료 안내도 실제 배너 너비에 맞춥니다. 세로 사이드바는 사용자가 제공한 160×600 전용 코드를 사용합니다. PC에서 상단 24px 간격을 유지하는 `position: sticky`로 스크롤을 따라오다가 콘텐츠 영역 끝에서 멈춥니다. 1050px 이하에서는 사이드바를 숨기며 숨겨진 배너는 광고 요청도 하지 않습니다. 짧은 화면에서는 배너 전체와 안내를 읽을 수 있도록 따라오기 동작을 끕니다.

공식 `https://ads-partners.coupang.com/g.js`는 페이지당 한 번만 불러오며, 공식 스크립트의 `container` 옵션으로 각 위치를 지정합니다. 화면 근처에 온 배너만 로딩하며 크기를 미리 예약합니다. 화면 크기가 바뀌어도 광고를 반복해서 재생성하지 않습니다. 광고 차단·네트워크 오류로 스크립트를 불러오지 못하면 해당 영역을 숨깁니다. 사용자 코드의 ID·추적 코드·크기만 구조화해 저장하며 임의 HTML/JavaScript를 원고에 주입하지 않습니다.

| 위치 | 권장 PC 크기 | 권장 모바일 크기 |
| --- | --- | --- |
| home-top / home-middle / home-bottom | 728×90 또는 970×90 | 320×100 또는 300×250 |
| article-top / article-middle / article-bottom | 728×90 | 320×100 또는 300×250 |
| home-sidebar / article-sidebar-top / article-sidebar-bottom | 160×600 (현재 설정) 또는 300×250 | 1050px 이하 화면에서 숨김 |

이 수치는 레이아웃용 권장값입니다. 쿠팡이 실제로 제공하는 배너의 가용 규격을 보장하지 않습니다. 제공받은 원본 크기를 입력하면 화면 너비에 맞게 축소하고 종횡비를 유지합니다. 모바일용 이미지가 없으면 PC 이미지가 축소됩니다. 긴 가로 배너는 모바일에서 작아지므로 별도 모바일 이미지를 권장합니다.

아래는 형식을 설명하는 예시이며 실제 링크가 아닙니다.

```json
{
  "enabled": true,
  "banners": [{
    "id": "article-middle-example",
    "slot": "article-middle",
    "categories": [],
    "href": "https://link.coupang.com/a/REPLACE_WITH_REAL_LINK",
    "alt": "쿠팡에서 상품 살펴보기",
    "desktop": {"src": "https://example.com/replace-desktop-banner.webp", "width": 728, "height": 90},
    "mobile": {"src": "https://example.com/replace-mobile-banner.webp", "width": 300, "height": 250}
  }]
}
```

`categories`를 비우면 전체 카테고리에 표시합니다. 홈 배너에는 빈 배열을 사용합니다. 각 위치에는 배너 1개씩 등록합니다. 위 JSON은 기존 이미지 배너 형식이며, 다이나믹 배너는 `type: "dynamic"`, `widget`, `desktop`, `mobile`을 사용합니다. 실제 설정 파일에서 현재 연결된 값을 확인할 수 있습니다.

배너 바로 아래에는 **이 배너는 쿠팡 파트너스 활동의 일환으로, 이를 통한 구매 시 일정액의 수수료를 제공받습니다.** 문구를 `bannerDisclosure`에서 삽입합니다. 홈은 포스팅이 아니므로 포스팅 안내를 표시하지 않습니다. 글에도 배너만 있을 때는 각 배너 아래 안내를 사용합니다.

글 본문에서 직접 상품 제휴 링크를 사용하는 경우에만 글 첫 부분에 **이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.** 문구를 `affiliateDisclosure`에서 삽입합니다. 직접 작성하는 제휴 링크에는 `rel="sponsored"`를 적용합니다. 다이나믹 배너 내부 링크는 쿠팡의 외부 iframe이 제공하므로 사이트에서 수정하지 않습니다. 개인정보처리방침과 광고·제휴 안내에도 쿠팡 외부 서비스 사용을 반영합니다. 준비된 모든 슬롯을 채우지는 않습니다. 팝업·전면 광고·본문을 가리는 고정 배너는 사용하지 않습니다. 공식 가이드의 배너와 포스팅 안내 예시: https://partners.coupangcdn.com/partners-guide/partners-guide-20251028182159.pdf
