# 처음 접하는 독자를 위한 작성 기준

우선순위는 독자가 글의 뜻과 다음 행동을 이해하는 것이다. 부록·연습 자료 확대보다 원고의 설명을 먼저 개선한다. 새로운 주제 제한이나 카테고리는 추가하지 않는다.

2026-10-17 기준 독자는 해당 분야와 전혀 관련이 없고 배경지식도 없는 비전문가 중학생이다. 어려운 용어를 쉬운 말로 바꾸는 것뿐 아니라, 대상·행동·이유·결과 사이에 생략된 연결을 설명한다. 독자의 나이를 본문에 내세우거나 어린아이를 대하듯 쓰지 않는다.

- 기본 용어와 약어도 처음 나오면 쉬운 뜻을 풀이한다. 필요한 예시는 하나의 작은 상황으로 연결하고 대상·이름·값을 일관되게 사용한다.
- 절차는 시작 위치부터 한 단계 한 행동으로 설명한다. 근거에 있는 메뉴 경로와 확인 결과를 연결하고, 수식·명령은 복사 가능한 완성 예시와 뜻을 함께 제공한다. 확인되지 않은 화면·메뉴를 만들지 않는다.
- 스크린샷 없이도 이해할 설명을 기본으로 한다. 캡처 확보를 필수 조건으로 만들거나 작성 분야를 제한하지 않는다.
- 첫 작성 응답 안에서 설명을 다듬는다. 별도 가독성 평가 모델·유료 문체 교정 단계를 추가하지 않는다. 저비용 작성·기존 독립 검수·월 $7 제한을 유지하며 문체 선호만으로 재검수하지 않는다.

위 기준을 실제 작성·분량 보완·사실 수정·검수 프롬프트에 함께 반영했다. 이 변경만을 위한 유료 샘플 생성이나 기존 글 전체 재작성은 실행하지 않는다.

- 기본 방법을 먼저 설명하고 필수 준비 조건은 해당 행동 전에 둔다. 드문 예외는 뒤에서 다룬다.
- 낯선 용어는 필요한 자리에서 풀고, 지금 하는 행동의 이유와 결과 판단을 연결한다. 근거 없는 화면·메뉴·성공 문구는 만들지 않는다.
- 이유는 연결된 짧은 문단으로, 실제 순서는 번호 목록으로 쓴다. 본문 전체를 체크리스트로 만들거나 출처·면책 문구를 매 문단 반복하지 않는다.
- 실제 본문 최소 3,500자, 목표 약 4,000자다. 절별 글자 수 할당과 반복으로 채우지 않으며 최소 분량에서 설명이 완결됐다면 불필요하게 늘리지 않는다. 분량은 SEO나 광고 승인 보장이 아니다.
- 검수는 필수 선행 단계 누락·잘못된 변경 범위처럼 실행에 지장을 주는 실제 오류를 지적한다. 더 친절한 문체를 선호한다는 이유만으로 거절·재호출하지 않는다.

## 적용과 확인

2026-10-16에 `n8n/prompts/`의 작성·분량 보완·사실 수정·독립 검수 4개 프롬프트를 수정했다. 실제 n8n 본체 `HUqCE3BE3JSNPhI3`의 Configuration과 검수 `FQg1yF0O4shWkDbQ`의 Review Evidence and Images에 저장하고 다시 읽어 일치를 확인했다.

기존 모델·출력 JSON·재시도 한도·비용 제한·승인 경로·연결·비활성 스케줄을 유지했다. 기존 게시 원고와 revision은 변경하지 않았고 유료 원고 생성·검수는 실행하지 않았다. 프롬프트 입력 길이는 조금 늘지만 AI 호출 단계는 추가하지 않는다. 새 원고의 실제 품질은 다음 생성 결과에서 확인해야 한다.

같은 날 사용자가 분량 기준을 낮추도록 요청하여 최소 3,500자·목표 약 4,000자로 변경했다. n8n의 생성·보완·중복 맵·이미지 복구·검수·승인·배치 분기와 사이트의 발행 검사에도 같은 하한을 적용한다. 보완은 3,500자 미만일 때만 분량 부족으로 실행하며 약 4,000자까지 필요한 설명을 보충한다. 3,500~4,000자 원고를 목표 분량에 못 미쳤다는 이유만으로 늘리지 않는다. 기존 게시 글을 줄이거나 다시 생성하지 않는다.

역할·구체적 지침·문체 예시를 구분하는 구성은 [OpenAI 공식 프롬프트 작성 안내](https://developers.openai.com/api/docs/guides/prompt-engineering)를 참고했다. 한국어 초보 독자에 관한 세부 편집 기준은 이 프로젝트의 운영 선택이다.
