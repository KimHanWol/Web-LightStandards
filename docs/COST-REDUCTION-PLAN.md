# 비용 절감 계획 — 2026-10-17

기준: 최근 추가 배치에서 발행한 18편의 평균 $0.09458. 보류된 다른 주제의 비용은 이 평균에서 제외한다. 1차 목표는 같은 모델·발행 품질 기준에서 편당 약 $0.06–0.08이며, 변경 후 실제 원고에서 확인할 예상치다. 별도 유료 벤치마크를 추가로 돌리지는 않는다. 월 $7 제한을 유지한다.

## 이번 변경

- 새 원고는 이미지 기본 3장, 별개의 설명에 꼭 필요한 경우만 4장. 작성 응답 schema, 이미지 반복 생성, 무료 사진 선별, 검수 응답, 승인, 사이트 검증을 함께 변경한다.
- 무료 사진 검색을 먼저 실행하고, 적합성과 상업적 사용 라이선스를 확인한 사진으로 채운 뒤 부족분만 생성한다. 저작자·원본 링크·라이선스 기록을 유지한다.
- 생성비는 기존 5장 $0.015에서 3장 $0.009, 4장 $0.012. 이미지 교체가 없을 때의 기본 금액이다. 검수에 실제 존재하는 사진만 보내며, 없는 4·5번째 사진을 요청하지 않는다.
- 작성 요청에는 완성 글의 주제 맵을 한 번만 보내고, 같은 카테고리·다른 카테고리 분류는 해당 ID를 참조한다. 기존 질문·범위·다룬 내용·별칭 정보는 삭제하지 않는다.
- 검수 요청에서는 비용·이미지 처리 이력 등 내부 상태를 제거한다. 실제 원고·근거·주제 범위·기존 글의 범위·첨부 이미지 정보는 유지한다.
- 이미 발행했거나 이전 정책으로 생성 중인 5장 원고는 원고와 승인 revision을 훼손하지 않고 처리한다. 새로 쓰는 원고의 4장 상한과 기존 데이터 호환을 구분한다.

## 다음 실행 기록을 보고 조정할 항목

1. 무료 검색은 원고당 1회, 사진 선별도 후보를 모아 한 번에 처리한다. 무료 사진 자체는 $0이나 AI 시각 선별은 유료이므로, 후보 수·전달 이미지 크기·응답 길이를 줄이고 실제 선별 비용과 부족분 생성비를 비교한다. 관련성 없는 사진을 수를 맞추려고 사용하지 않는다. 현재 남은 3장 생성비 $0.009가 비교 기준이다.
2. 작성 모델이 한 응답에서 문장을 다듬고 완성하도록 한다. 단순 문체 선호 때문에 별도 유료 재작성·검수를 추가하지 않는다. 기존 전체 재작성보다 소제목별 보완·지적된 사실 문단·문제 이미지 교체를 우선하는 흐름을 유지한다.
3. 글자 수·소제목·출처 URL·중복 문단·이미지 수·라이선스·동일 intent는 코드로 먼저 검사한다. 이런 형식 오류를 유료 검수에 넘기지 않는다. 의미가 같은 글인지와 근거에 맞는지의 독립 검수는 유지한다.
4. 원고·사실·이미지를 최종 검수 한 번에서 함께 확인한다. 재검수는 실제 지적 사항을 고친 경우에만 실행한다. 같은 revision의 이미 통과한 부분을 다시 생성하지 않는다. 현재 있는 제한된 자동 보완 횟수를 늘리지 않는다.
5. 품질 유지는 새 글이 질문에 답하는지, 중요한 메뉴·조건이 근거와 맞는지, 사진이 실제 내용에 필요한지로 확인한다. 비용을 줄이기 위해 근거를 무작정 자르거나 오류가 남은 원고를 승인하지 않는다.

원고가 적합성 보류된 경우에도 완료된 API 응답은 과금된다. 이런 시도를 포함한 운영 평균과, 정상 발행한 한 편의 비용을 계속 분리해서 집계한다.
