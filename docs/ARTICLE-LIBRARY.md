# 전체 글과 공통 우측 배너

2026-10-16 사용자 요청으로 전체 글을 `/articles/`의 정적 페이지 목록으로 분리했다. 첫 요청에는 글 카드 12개만 포함하며 아래쪽에 가까워지면 다음 HTML 페이지에서 12개씩 추가한다. 현재 34편은 12→24→34 순서다. 로딩 실패 시 자동 반복 요청을 멈추고 ‘글 더 보기’로 재시도한다. 마지막 페이지에서는 버튼과 자동 요청을 종료한다.

`/articles/2/`처럼 실제 다음 페이지 주소가 있어 JavaScript가 꺼져도 페이지 링크로 이동할 수 있다. 검색은 본문을 포함하지 않은 `/articles/index.json`의 제목·설명·별칭 목록에서 찾고 결과를 12개씩 표시한다. 기존 `/?view=all`, `/?q=...`, `/?category=...` 주소는 조건을 보존해 새 목록으로 연결한다. 전체 글 링크는 상단에서 홈 바로 다음에 배치했다.

홈·카테고리·전체 글·소개·문의·정책 페이지는 `PageFrame.astro`의 공통 160×600 우측 배너를 사용한다. 본문 글의 기존 우측 배너는 유지한다. 기존 쿠팡 ID 1038395와 수수료 고지를 재사용하며, 넓은 화면에서는 top 24px sticky, 폭 1050px 이하에서는 숨긴다. 글 추가 로딩 중 광고를 새로 만들지 않는다. 홈 중간 970×90 / 728×90 배너 설정은 유지했다.

소개·문의·광고 안내에는 기존 브랜드 로고와 가벼운 SVG 그림을 적용하고 탐색 방법·오류 제보 항목·광고와 직접 제휴 링크의 구분을 보강했다. 문의 주소와 기존 개인정보처리방침은 유지하며 운영 성과·실사용·회신 기한은 만들어 넣지 않는다.

검증: 초기 12개 및 24개→34개 추가 로딩·중복 없음·마지막 종료, 첫 페이지 밖 PDF 글 검색, PC sticky top 24px, 모바일 우측 광고 숨김·가로 넘침 없음, 문의·광고 안내 렌더링. 로딩 중 중복 요청·실패 재시도·순환 응답과 검색 범위는 오프라인 테스트로 확인한다.

정적 페이지 구성은 [Astro 공식 페이지 나누기 안내](https://docs.astro.build/en/reference/routing-reference/#paginate)를 참고했다.
