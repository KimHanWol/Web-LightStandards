# 광고 배치와 배너 종류

확인일: 2026-10-15. 제안과 현재 연결된 광고를 구분한다. 수익·클릭률의 우열은 아직 측정하지 않았다.

## 참고한 실제 화면

- [How-To Geek 홈](https://www.howtogeek.com/): 주요 글·보조 글·최근 글을 독립적으로 배치한다. 주요·보조 글은 왼쪽에 묶고, 오른쪽은 사각 광고와 짧은 최근 글 목록으로 구성해 양쪽 높이를 맞춘다. 참고 사이트의 실제 광고 위치를 복제한 것이라는 뜻은 아니다.
- [MakeUseOf 홈](https://www.makeuseof.com/): 주요 글, 최근 글, 분야별 콘텐츠 모음을 구분한다. 홈의 광고는 글 묶음 사이의 독립된 영역으로 설계한다. 이 위치는 우리 사이트에 맞춘 설계이며, 해당 사이트에서 동일한 광고가 송출된다고 주장하지 않는다.
- [How-To Geek 상품 글](https://www.howtogeek.com/grab-this-ryobi-one-multi-tool-and-orbit-sander-for-half-off/): 설명 대상인 실제 제품의 이미지·가격·판매처 링크가 있는 상품 카드를 본문에 배치한다. 우리 글에서도 실제 관련 제품과 검토된 제휴 링크가 있을 때만 이 방식을 사용한다. 가격·할인율·실사용 경험은 만들어 넣지 않는다.
- [쿠팡 파트너스 공식 가이드](https://partners.coupangcdn.com/partners-guide/partners-guide-20251028182159.pdf): 다이나믹 배너의 파트너스 추천·카테고리 베스트·고객 관심 기반 추천·상품 직접 선택 유형과 크기·테두리 설정을 확인했다. 같은 carousel 코드라도 상품 선택 방식은 쿠팡에서 생성한 배너 ID에 연결된다.

참고 사이트의 광고는 지역·동의·광고 차단·경매 결과에 따라 다를 수 있다. 화면만 보고 해당 사이트의 개인화 방식이나 쿠팡 유형, 광고 수익을 추정하지 않는다.

## 적용한 배치

| 영역 | 형식 | 현재 설정 / 다음 단계 |
| --- | --- | --- |
| 홈 상단 왼쪽 | 주요 글 + 작은 보조 글 | 보조 글을 같은 열에 묶어 읽기 흐름을 유지한다. |
| 홈 상단 오른쪽 | 336×280 사각 광고 + 최근 글 3개 | ID 1038387. 좁은 PC 열에서는 300×250. 광고를 첫 화면에 노출하고 주요 글 열과 전체 높이를 맞춘다. 작은 화면에서는 주요·보조 글 다음에 배치한다. |
| 홈 분야 글 묶음 2개 뒤 | 970×250 / 좁은 PC에서는 728×250 | ID 1038394. 얇은 728×90 띠를 넓고 높이 있는 상품 영역으로 변경한다. 모바일에서는 이 두 번째 광고를 숨겨 상단 사각 광고와 중복 노출하지 않는다. |
| 글 본문 절 사이 | PC 728×90 / 작은 화면 300×250 | 생활·주거 글의 article-middle은 카테고리 베스트(PC 1039597 / 모바일 1039598). 다른 위치·다른 분야는 기존 관심 기반 추천 유지. 현재 이 분야의 실제 글은 제습기·식기세척기·건조기·냉장고 4편이다. |
| PC 글 오른쪽 | 160×600, 스크롤 시 sticky | 기존 ID 1038395 사용. 작은 폭에서는 숨김. |
| 실제 제품을 다루는 글 | 해당 제품 이미지·설명·구매 링크 | 검토된 제휴 링크가 있는 글에서만 기존 상품 카드 사용. 상품 직접 선택 배너도 가능하나 별도 코드 필요. |
| 글 하단 | 본문과 분리한 가로/사각 광고 | 기존 관심 기반 추천 유지. 무작위 유형 교체나 중복 슬롯 추가는 하지 않는다. |

광고 표시와 배너 수수료 안내는 각 광고 아래에서 읽을 수 있게 유지한다. 본문에 직접 제휴 링크가 있으면 글 첫 부분의 제휴 안내도 유지한다. 광고 실패 시 해당 영역을 숨기며, 외부 스크립트는 한 번만 로드하고 광고가 화면 근처에 왔을 때 요청한다.

970×250과 336×280은 기존 배너 ID에 공식 위젯의 크기 매개변수를 전달해 실제 상품 표시를 확인한 규격이다. CSS로 원래의 90px 높이 광고를 늘려 보이게 하지 않는다. 원고 본문과 세로 배너의 기존 크기는 유지한다.

## 광고 종류 선택

- **고객 관심 기반 추천**: 여러 주제의 독자가 오는 홈·일반 도움말·사이드바의 기본값. 현재 사용자 제공 코드의 설정은 사용자의 선택에 근거하며, JS의 carousel 값만으로 구별할 수는 없다.
- **카테고리 베스트**: 제품 분야와 구매 의도가 분명한 글의 본문 중간에 우선 시험한다. 첫 후보는 실제 발행된 가전 관련 글이다. 사이트의 여행·문화 같은 큰 분류에 맞춰 엉뚱한 상품을 강제로 넣지 않는다.
- **상품 직접 선택**: 실제 특정 상품을 설명·비교하는 글에서 사용한다. 일반 앱 사용법 글에 임의 제품을 끼워 넣지 않는다.
- **파트너스 추천**: 범용 관심 기반 광고와 역할이 겹치므로 초기 기본값을 전부 바꾸지 않는다. 추후 별도 코드로 같은 위치를 비교할 수 있다. 단순히 유형 수를 늘린다고 수익이 오르는 것은 아니다.

## 연결한 코드 — 2026-10-16

사용자가 제공한 카테고리 베스트 코드 PC **1039597**, 모바일 **1039598**을 `article-middle`의 `생활·주거` 전용 배너로 연결했다. 본문 중간의 안전한 광고 자리가 있으면 그곳에서 기본 광고를 대체한다. 중간 자리가 없는 글은 글 끝의 기존 광고 한 곳을 대신 사용한다. 따라서 가전 글마다 이 유형은 한 곳에만 표시하며 광고 개수는 늘리지 않는다. 원고 Markdown에 광고 코드를 넣지 않는다. 다른 분야 본문과 홈·세로 배너는 그대로다. 이 연결을 위한 추가 코드는 필요 없다.

## 발급 당시 요청 규격

우선 가전 관련 글의 본문 중간 광고만 다른 유형으로 비교할 수 있도록, 쿠팡에서 다음 **2개 코드**를 만들면 된다.

1. 카테고리 베스트 → 가전/디지털 → **728×90**, 테두리 없음.
2. 동일한 타입·카테고리 → **300×250**, 테두리 없음.

제목 예: `LightStandards - 가전 본문 PC`, `LightStandards - 가전 본문 모바일`. 계정에서 제공하는 실제 카테고리 명칭을 확인하고 선택한다. 쿠팡에서 발급된 두 ID를 전달받은 뒤 `config/affiliate-banners.json`의 `article-middle`에 실제 원고 category를 지정해 추가한다. 다른 글·다른 위치의 기본 광고는 그대로다. 발급 전에는 ID나 상품 설정을 임의로 만들지 않는다.

한 슬롯에는 기본 배너 1개와 겹치지 않는 category별 배너를 함께 등록할 수 있다. 해당 category가 있으면 전용 배너 **1개가 기본 배너를 대체**하고, 없으면 기본 배너 1개만 보여 준다. 중복 category 설정은 검증에서 거절한다. 별도 배너의 테두리는 우리 외곽선과 중복되지 않게 없음으로 선택한다.

추후 비교할 때는 위치·규격을 고정하고 한 번에 상품 선택 방식만 바꾼다. 쿠팡에서 구분 가능한 추적 설정을 함께 사용하고 클릭·주문·수익과 페이지 속도를 확인한다. 현재는 유형별 성과 데이터가 없으므로 특정 유형이 더 수익성이 높다고 단정하지 않는다.
