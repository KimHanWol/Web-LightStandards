# 검색 응답 확인과 제목 개선 — 2026-10-17

사용자가 공개 응답·열린 Search Console 실적 확인과 제목 개선을 요청했다. 새 원고 생성과 유료 검수는 실행하지 않았다.

## 확인한 상태

- 공개 사이트맵 인덱스와 하위 XML은 HTTP 200, application/xml이다. robots.txt도 HTTP 200이고 검색 허용 및 올바른 사이트맵 주소를 포함한다.
- 사이트맵에 포함된 90개 HTML 주소를 검사했다. 73개 글과 탐색·정책 페이지 모두 최종 HTTP 200, 고유 title, H1 하나, 자기 주소 canonical, description, noindex 없음으로 확인했다. 첫 검사에서 전체 글 목록에 일시적 연결 실패가 있었으나 해당 주소 재확인 및 전체 검사 재실행에서는 정상이다.
- Googlebot User-Agent 요청도 200이지만 이것만으로 실제 Google 크롤링을 입증하지 않는다. 별도로 Search Console의 시험 글 실제 URL 테스트가 'URL을 Google에 등록할 수 있음', '페이지 색인을 생성할 수 있음'을 표시했다.
- Search Console 실적 화면은 3개월 선택, 노출 0·클릭 0·검색어 없음이며 표시된 차트 범위는 10월 13~14일이다. 최신 확정 실적이나 검색 수요·제목별 CTR이 확보됐다는 뜻이 아니다.
- 페이지 색인 보고서는 '데이터를 처리하는 중'이다. 사이트맵 보고서는 10월 15일 마지막 읽기, 두 XML 모두 '가져올 수 없음', 발견 페이지 0이다. 시험 글의 Google 색인 데이터는 '아직 알려지지 않은 URL'이다. 공개 응답 정상 및 실시간 가져오기 성공과 구분하며, Google 보고서의 실패 원인을 확인 없이 단정하지 않는다.

## 변경

- 73개 기존 제목을 살펴보고 추상적·장황한 표현, 어색한 대상 이름 등을 34개 제목에서 개선했다. 검색 성과가 아직 없으므로 검색량이나 CTR 개선을 근거로 내세우지 않는다. 본문에서 다루는 대상·작업·적용 범위에 맞췄다.
- `config/article-titles.json`은 사용자 요청으로 검토한 표시 제목이다. 원래 승인된 본문·원고 제목·revision·n8n 영수증은 바꾸지 않는다. 원본 제목과 revision이 모두 일치할 때만 적용되므로 미래에 승인된 새 원고를 오래된 제목으로 덮지 않는다.
- 공통 글 조회에서 제목을 적용하여 title·H1·Open Graph·구조화 데이터·목록·검색·RSS에 동일하게 반영한다. 기존 URL은 유지한다.
- 글 공유 이미지는 로고 대신 해당 글의 기존 검토 이미지를 쓰고 og:type은 article로 표시한다. 이미지 생성·다운로드 요청은 추가하지 않는다.
- 이후 작성용 실제 n8n 프롬프트에도 간결하고 구체적인 제목, 키워드 반복·과장·추상적 꼬리말 금지를 반영했다. 생성·발행 큐와 스케줄은 재시작하지 않았다.

검증: 자동 테스트 69개, 승인 원고 73개 검증과 사이트 빌드·자원 용량 검사, 수정한 34개 글의 title/H1/og:title/구조화 데이터 일치 확인. 공개 재점검에는 `node scripts/audit-search.mjs`를 쓴다. 개별 응답 상세는 비공개 `.local/search-audit.json`에 저장한다.

기준: https://developers.google.com/search/docs/appearance/title-link?hl=ko

## 배포와 제출 확인

- 변경 커밋 `c459bec9ecb644614be4cc439412adb145b8ca76`, GitHub Actions `39023565722`가 성공했다. 실제 공개 34개 글에서 새 H1 일치를 확인했고 배포 후 90개 URL 응답 검사도 통과했다.
- 검증한 `sitemap-index.xml`을 한 번 재제출했고 Search Console의 '사이트맵이 제출됨' 확인을 받았다. 제출 접수는 XML 수집 성공이나 색인 완료와 같지 않다.
- 아직 Google에 알려지지 않은 시험 글 `docs-guide-63175-20261016`에 색인 생성을 한 번 요청했다. '색인 생성 요청됨 / 우선순위 크롤링 대기열에 추가' 확인을 받았다. 반복 제출이나 전체 URL 일괄 요청은 하지 않았다.
- 계정 화면 증거는 `.local/sitemap-resubmitted-20261017.png`, `.local/index-requested-20261017.png`로 비공개 보관한다. Google의 색인 완료와 사이트맵 정상 처리 여부는 아직 확정하지 못했다.
