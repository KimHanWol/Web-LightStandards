## 이미지 보완 경로

압축된 배치 액션은 본문·오류 전문을 전달하지 않는다. 그런데 본체의 `Identify Repair Scope`는 전달된 오류 문구를 요구해서 `repair_images`를 글 사실 수정으로 잘못 보냈다. 실행 4619에서 이 경로와 이미지 오류에 대해 원고 수정이 불필요하다는 모델 응답을 확인했다.

압축 이미지 액션은 먼저 실제 원고 행을 다시 읽도록 고쳤다. `Prepare Existing Draft`가 현재 상태·실제 검수 유형·이미지 번호·보완 횟수를 다시 검사하며, 글 사실 오류를 이미지 교체로 처리하지 않는다. 회귀 테스트는 압축 액션 → 실제 행 읽기 → 문제 이미지 분리까지 확인한다.

실행 4512, 4543, 4557, 4570, 4601, 4619, 4632의 앞뒤 본문·이미지를 비교했다. 잘못된 글 수정 시도에서 본문과 이미지가 변하지 않은 7개 행만 `n8n/recovery/image-misroutes-20261017.json`에 기록했다. ID·revision·기존 오류·원래 검수 응답 ID·본문/이미지 서명을 모두 대조해서 실패한 이미지 검수를 이어받는다. 이전에 청구된 비용과 보완 횟수는 초기화하지 않는다. 이 처리는 승인이나 발행이 아니며, 이미지 교체 후 새 revision의 독립 검수를 통과해야 한다.
