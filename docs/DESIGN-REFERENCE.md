# 검색형 수익 정보 사이트 구성

사용자가 요청한 목적은 검색량·경쟁·수익성 데이터로 검토한 주제의 정보 글을 발행하고 광고와 제휴로 수익화하는 것이다. 특정 생활·디지털·수납 분야는 승인되지 않았다.

2026-10-14 [Lifewire](https://www.lifewire.com/)의 실제 브라우저 화면을 확인했다. 흰 배경, 간결한 로고와 메뉴, 검색, 상단 광고, 큰 대표 기사, 옆 기사 목록, 최신 글과 주제별 묶음을 사용한다. 홈페이지에는 연간 독자 2억 명이라는 자체 집계가 표시돼 있다. 독립적인 트래픽 검증이나 수익 분석을 한 것은 아니다. [소개 페이지](https://www.lifewire.com/about-us-5081224)에는 광고·협찬과 상품 구매 수수료 운영을 설명한다. 해당 매체의 기술 주제, 원고 정책, 운영 실적과 이미지는 가져오지 않는다. 디자인의 검색·목록·광고 구조만 참고한다.

| Before | After | Why |
| --- | --- | --- |
| 고정 생활 주제 메뉴와 연출 사진 | 실제 발행 글에서 생성하는 카테고리 | 검색 데이터에 따라 주제를 정한다는 사용자 요구 |
| 큰 브랜드 슬로건과 편집 원칙 소개 | 검색, 최신 글, 글 제목·요약·사진 | 글을 빠르게 찾는 방문 목적 |
| 홈 배너에도 포스팅 고지 | 각 배너 바로 아래 배너 수수료 안내 | 배너와 포스팅의 경제적 관계를 구분 |
| 생활 정보 매체라는 생성 프롬프트 | 검토한 키워드와 검색 의도를 따르는 프롬프트 | 주제 선정과 생성 단계의 임의 가정을 제거 |

공개 페이지는 소개·문의·개인정보처리방침·광고 안내를 유지한다. 편집 원칙 페이지는 제거했다. 실제 발행 글은 아직 0개이므로 주제와 글을 임의로 채우지 않고 빈 목록을 표시한다. 생성 비용 제한과 승인 revision 검증은 그대로 유지한다.

## 로고와 광고 배치 개선

2026-10-14 후속 수정에서는 남색 심볼과 파란색 포인트의 새 로고를 적용했다. 한글은 [Pretendard 1.3.9](https://github.com/orioncactus/pretendard)의 가변 다이나믹 서브셋을 자체 호스팅한다. unicode-range와 font-display: swap을 유지해 해당 화면에서 사용하는 범위만 받도록 구성했다. 외부 폰트 CDN 연결은 방문 시 필요하지 않다. 원본 라이선스는 public/fonts/pretendard/OFL.txt에 포함했다.

| Before | After | Why |
| --- | --- | --- |
| 녹색 LS 로고와 작은 브랜드 글자 | 남색·파란색 새 심볼, 크게 정돈한 한글 워드마크 | 로고의 식별성과 화면 전체 색상 일관성 |
| 광고가 빈 홈 화면 대부분을 차지 | 글이 없으면 광고 없음, 다섯 개의 글 뒤 가로 배너 하나 | 읽을 정보와 광고의 비중 조절 |
| 홈의 160×600 사이드 광고 | 긴 글 페이지의 오른쪽에서만 사용 | 세로 배너에 맞는 콘텐츠 길이와 공간 |
| 배너보다 넓은 안내 문구 | 배너 실제 너비에 맞춘 라벨과 안내 | 광고 단위의 정렬과 명확한 경제적 관계 표시 |
| 동일한 글 카드 | 큰 대표 글, 이미지·제목 중심의 나머지 목록 | 제목과 이미지의 시각적 우선순위 |

빌드 및 기존 자동 검증을 수행했다. 로컬 HTTP 응답과 생성 HTML 구조를 확인했으며, 브라우저에서 변경 후 레이아웃을 시각 검증했다고 주장하지 않는다. 화면 미리보기는 실제 발행 글이 없는 상태다.

## 헤더와 글꼴 후속 수정

2026-10-14 [토스 테크](https://toss.tech/)의 실제 화면과 DOM 스타일을 확인했다. 작은 로고를 좌측에 두고 메뉴를 같은 높이에 정렬하는 구성을 참고했다. 해당 사이트의 전용 Toss Product Sans는 복제하지 않고, 기존 자체 호스팅 Pretendard를 유지하면서 제목은 600~700, 메뉴는 500, 본문은 400 굵기로 조정했다. 과도한 음수 자간도 줄였다.

| Before | After | Why |
| --- | --- | --- |
| 로고 그림이 PNG 좌우 경계에 닿음: 가장자리 유색 픽셀 140개 | 원본에서 다시 축소하고 좌우 16px 투명 여백 확보: 가장자리 유색 픽셀 0개 | 이미지 파일 자체의 잘린 듯한 외곽을 수정 |
| 52px 심볼과 한글·영문 두 줄 헤더 | 36px 심볼과 한글 이름 한 줄, 헤더 높이 88px | 심볼과 이름의 수평 정렬, 지나치게 큰 헤더 개선 |
| 720~780의 굵기와 큰 음수 자간 | 500·600·700 중심 굵기와 완만한 자간 | 한국어 제목과 메뉴를 차분하게 정리 |

확인 범위는 이미지 픽셀 경계, 정적 빌드와 로컬 HTTP 응답이다. 로컬 사이트의 브라우저 시각 검증은 수행하지 않았다.
