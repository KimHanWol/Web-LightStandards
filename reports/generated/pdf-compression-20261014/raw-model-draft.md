# PDF 용량 줄이기: Windows Acrobat, Mac 미리보기, 웹 압축 절차와 품질·글꼴·보안·제출 전 점검법

PDF 파일의 용량을 줄이는 작업은 다양한 운영체제와 소프트웨어 환경에서 진행할 수 있으며, 문서 유형과 제출 목적에 따라 적합한 방법과 주의점이 달라집니다. 이 글에서는 Windows의 Adobe Acrobat, Mac의 미리보기 앱, 웹 기반 Adobe Acrobat 압축 서비스를 중심으로 각각의 절차를 자세히 살펴보고, 이미지 압축과 글꼴 포함, 스캔 문서 설정, 결합 문서 관리, 압축 실패 원인과 제출 전 점검 방법까지 폭넓게 다룹니다.

## PDF 유형과 원본 및 제출 규격 확인

PDF 문서는 텍스트 중심, 이미지 중심, 스캔 문서 등 다양한 유형으로 나뉩니다. 각 유형에 따라 용량 줄이기 방식과 적용할 최적화 설정이 달라집니다. 텍스트 위주 문서는 글꼴 포함 여부와 중복된 요소 정리가 용량에 영향을 미치고, 이미지가 많은 문서는 이미지 압축과 해상도 조정이 핵심입니다. 스캔 문서는 스캔 시 해상도와 색상 모드 설정이 최종 용량과 품질을 좌우합니다.

원본 파일을 압축하기 전에 반드시 제출 기관이나 사용 목적에 맞는 규격을 확인해야 합니다. 예를 들어, 최대 파일 크기, 해상도, 색상 모드, 글꼴 포함 요구 사항 등이 다를 수 있으므로, 이를 충족하지 못하면 제출이 반려되거나 문서가 제대로 인식되지 않을 위험이 있습니다. 따라서 압축 전 원본 파일을 백업해 두고, 제출 규격을 먼저 파악하는 것이 선행되어야 합니다.

## Windows Acrobat에서 PDF 용량 줄이기 절차와 호환성, 저장본 구분

Windows 환경에서 Adobe Acrobat을 사용해 PDF 용량을 줄이려면, 공식 도움말에 따라 Menu에서 [File] - [Save as Other] - [Reduced Size PDF]를 선택합니다. 이 과정에서 "Make compatible with" 옵션을 통해 호환성 대상을 지정할 수 있는데, 이는 PDF를 열어볼 리더기의 버전과 호환성을 결정합니다. 다만, 메뉴 이름과 위치는 Acrobat 버전과 언어 설정에 따라 다를 수 있으므로 비슷한 메뉴를 찾아야 합니다.

여러 PDF 파일을 한꺼번에 압축할 때는 "Apply to Multiple Files" 기능을 활용할 수 있습니다. 이때 "Add Files" 또는 "Add Open Files"로 대상 파일을 선택하고, 출력 폴더와 파일 이름 덮어쓰기 여부를 지정합니다. 하지만 모든 파일에 동일한 압축 설정이 적합한지 점검해야 하며, 문서 유형별로 압축 방식이 달라질 수 있음을 고려해야 합니다.

압축 후에는 새로운 파일로 저장하는 것이 일반적이며, 원본 파일을 덮어쓰지 않는 것을 권장합니다. 이렇게 해야 압축 결과에 문제가 생겨도 원본을 보존할 수 있습니다. 또한, 압축 과정에서 문서의 보안 설정이나 글꼴 포함 상태가 변할 수 있으므로, 저장 후 반드시 확인해야 합니다.

## Mac 미리보기 내보내기와 Quartz Filter, 화면용 옵션 활용법

Mac에서 PDF 용량을 줄일 때는 미리보기 앱을 이용해 PDF를 열고 [File] - [Export] 메뉴를 선택합니다. 이때 Quartz Filter에서 "Reduce File Size"를 선택하면 간단히 파일 크기를 줄일 수 있습니다. 저장 시 기존 파일을 교체할지 묻는 경우가 있는데, 원본 보존을 위해 다른 이름으로 저장하는 방법도 있습니다.

Quartz Filter는 macOS 버전과 환경에 따라 다르게 보일 수 있으며, 기본 제공 필터 외에 사용자가 직접 필터를 생성하거나 수정할 수도 있습니다. "Reduce File Size" 필터는 이미지 품질 저하가 발생할 수 있으므로, 압축 전후 파일을 비교해 품질 허용 범위를 판단하는 것이 필요합니다.

같은 내보내기 화면에서 "Create Linearized PDF" 옵션은 웹 브라우저에서 빠르게 로딩되도록 최적화하는 기능이며, "Optimize images for screen"과 "Save images as JPEG" 옵션은 각각 이미지 최적화와 JPEG 변환 설정입니다. 이 옵션들은 PDF 용량과 품질에 영향을 주므로, 용도에 맞게 선택해야 합니다.

## 웹 Acrobat 압축과 클라우드 저장, 다운로드 절차

웹 기반 Adobe Acrobat 압축 서비스는 Adobe 공식 홈페이지에서 "Convert" - "Compress a PDF" 메뉴를 통해 접근합니다. 사용자는 로컬 또는 클라우드 저장소에서 압축할 PDF 파일을 선택하고, 압축 수준을 High, Medium, Low 중에서 고를 수 있습니다. 압축 실행 후 결과 파일은 자동으로 Adobe 클라우드 저장소에 저장되며, 사용자에게 다운로드 알림이 표시됩니다.

이 과정에서 "Add files" 기능을 통해 여러 파일을 추가할 수 있지만, 웹 압축은 파일을 클라우드에 업로드하는 작업이므로 주민등록번호, 고객 정보 등 민감한 내용이 포함된 문서는 소속 기관의 업로드 허용 범위를 반드시 확인해야 합니다. 또한, 웹 압축은 모든 문서에 동일한 압축률과 품질을 보장하지 않으므로, 압축 후 결과물을 꼼꼼히 점검해야 합니다.

다운로드한 압축본은 로컬에서 별도로 저장하고, 원본과 비교해 품질과 글꼴, 보안 상태를 확인하는 절차가 필요합니다. 웹 압축은 편리하지만, 오프라인 환경에서 작업하는 것과는 차이가 있으므로 상황에 맞게 선택해야 합니다.

## 이미지 압축, 다운샘플링, 글꼴 포함, 레이어 변경 영향

Adobe Acrobat Pro의 PDF Optimizer 기능에서는 이미지와 글꼴, 레이어 등 다양한 요소를 세밀하게 조정할 수 있습니다. 이미지 압축은 컬러, 회색조, 단색 이미지별로 다운샘플링(해상도 낮추기)과 압축 방식을 선택합니다. 예를 들어, 점진적 색 변화가 많은 사진은 JPEG 계열 압축이 적합하고, 평면 색상의 삽화는 ZIP 압축이 더 효과적일 수 있습니다.

"Optimize images only if there is a reduction in size" 옵션을 활성화하면, 실제 용량 감소가 있을 때만 이미지 최적화를 적용해 불필요한 품질 저하를 막습니다. 글꼴 포함 설정을 해제하면 해당 글꼴이 없는 시스템에서는 대체 글꼴로 표시되어 문서 모양이 달라질 수 있으므로, 제출용 문서라면 글꼴 포함 여부를 반드시 확인해야 합니다.

PDF 내 레이어와 투명도는 평면화할 경우 편집 가능성이 줄어들고, 용량 감소에 영향을 미칠 수 있습니다. 따라서 문서 편집 기능을 유지해야 한다면 레이어 평면화 여부를 신중히 결정해야 합니다. 불필요한 객체 정리(Clean Up) 기능은 중복된 요소나 숨겨진 데이터를 제거해 용량을 줄이지만, 영향이 불분명할 때는 기본 설정을 사용하는 것이 안전합니다.

## 스캔 문서 색상, 해상도, OCR 구분과 설정 방법

스캔한 PDF 문서는 색상 모드, 해상도, OCR(광학 문자 인식) 설정에 따라 용량과 품질이 크게 달라집니다. Adobe Acrobat 스캔 설정에서는 자동 감지, 컬러, 흑백, 회색조 중 색상 모드를 선택할 수 있습니다. 컬러는 용량이 크고, 흑백은 용량이 작지만 품질 차이가 큽니다.

해상도는 DPI 단위로 지정하며, 높은 DPI는 선명하지만 용량이 커집니다. 제출 기관의 요구사항을 먼저 확인하고 그에 맞게 해상도를 설정하는 것이 필요합니다. "Optimize Image" 옵션은 크기와 품질 균형을 조정하며, "Small Size/High Quality" 프리셋을 선택해도 무조건 용량이 줄어드는 것은 아닙니다.

OCR 기능은 스캔 이미지에서 텍스트를 인식해 검색과 선택이 가능하게 하지만, OCR 실행 자체가 용량 감소를 보장하지는 않습니다. OCR 언어와 출력 유형을 별도로 설정할 수 있으며, 텍스트 편집이 필요한 경우 활성화합니다. 무손실 압축인 ZIP 방식을 선택하면 이미지 품질을 유지하면서 용량을 줄일 수 있지만, 손실 압축 대비 용량 감소폭이 적을 수 있습니다.

## 결합 문서 옵션과 제출 페이지 보존 판단 기준

여러 PDF 파일을 결합할 때는 Adobe Acrobat의 [All tools] - [Organize pages] 메뉴를 사용합니다. 결합 후 페이지 순서를 재배열하거나 불필요한 페이지를 삭제할 수 있습니다. 이때 제출 요구 사항에 맞게 페이지 누락 여부를 반드시 확인해야 하며, 페이지 삭제가 항상 허용되는 것은 아닙니다.

결합 옵션 중 "Smaller File Size"는 큰 이미지를 화면 해상도로 낮추고 낮은 품질의 JPEG 압축을 적용해 웹이나 이메일 용도에 적합합니다. "Default File Size"는 문서 품질과 크기를 균형 있게 유지하며, "Larger File Size"는 데스크톱 인쇄용으로 고품질을 유지하지만 결과 파일 크기가 커질 수 있습니다.

원본 PDF가 이미 최적화되어 있을 경우, "Smaller File Size" 옵션이 크기 감소에 효과적일 수 있지만 모든 문서에 동일하게 적용되는 것은 아닙니다. 따라서 결합 전후 파일 크기와 품질을 비교하고, 제출 목적에 맞는 옵션을 선택해야 합니다.

## 압축 효과 미흡 또는 글자 흐림 현상 발생 시 점검 사항

압축 후 기대만큼 용량이 줄지 않거나, 글자가 흐려지는 현상이 발생할 수 있습니다. 이런 경우 원본 PDF의 구성 요소와 압축 설정을 점검해야 합니다. 예를 들어, 이미 최적화된 PDF는 추가 압축 효과가 제한적이며, 고해상도 이미지가 많으면 용량 감소가 어려울 수 있습니다.

글자가 흐려지는 경우는 이미지 압축 방식이나 해상도 조정이 과도하게 적용됐을 가능성이 큽니다. 글꼴 포함 설정이 해제되어 대체 글꼴이 적용되면서 가독성이 떨어질 수도 있습니다. 이런 문제는 압축 옵션을 변경하거나, 이미지 압축 방식을 JPEG에서 ZIP으로 바꾸는 등 다양한 설정을 시험해 보면서 해결할 수 있습니다.

또한, 보안 설정 충돌로 저장이 제대로 되지 않거나, 레이어 평면화가 문서 품질에 영향을 미칠 수 있으므로 압축 전후 문서 상태를 꼼꼼히 비교하는 것이 필요합니다.

## 제출 직전 파일 이름, 용량, 페이지, 글꼴, 텍스트 선택, 그림 비교 점검 순서

최종 제출 전에는 다음 항목을 순서대로 점검하는 것이 권장됩니다. 첫째, 파일 이름이 제출 기관의 규칙에 맞는지 확인합니다. 둘째, 파일 용량이 요구 사항을 충족하는지 확인합니다. 셋째, 페이지 수와 순서가 정확한지 다시 한번 점검합니다.

넷째, 글꼴이 정상적으로 포함되어 있는지 확인합니다. 글꼴이 누락되면 문서가 다르게 표시될 수 있으므로, Acrobat의 "Document Properties"에서 글꼴 탭을 확인하거나, 텍스트를 복사해 다른 프로그램에 붙여넣어 글꼴 깨짐 여부를 점검합니다.

다섯째, 텍스트 선택과 복사가 가능한지 확인해 OCR이 제대로 작동했는지 판단합니다. 여섯째, 그림과 이미지가 깨지거나 품질 저하가 없는지 원본과 비교합니다. 필요하면 인쇄 미리보기를 통해 출력 상태도 점검합니다.

이러한 점검 절차는 제출 실패를 줄이고, 문서의 전문성과 신뢰성을 유지하는 데 도움이 됩니다.
