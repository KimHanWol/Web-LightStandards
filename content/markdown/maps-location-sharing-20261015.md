구글 지도 실시간 위치 공유는 Android의 Google Maps에서 특정 사람이나 링크로 현재 위치를 보내는 기능입니다. 공유 시간과 대상을 고를 수 있고, 이동 중에는 도착 예정 시간과 경로 진행도 함께 보낼 수 있습니다. PC에서는 새 공유보다 이미 켜 둔 공유를 관리하는 쪽에 가깝습니다.

이 글은 Google Maps와 Google Account 도움말을 기준으로, Android에서 시작하는 방법과 중단하는 방법, 링크 공유와 경로 공유의 차이, 공유가 안 될 때 확인할 조건만 정리합니다. [Google Maps: real-time location sharing](https://support.google.com/maps/answer/15437054?hl=en&co=GENIE.Platform%3DAndroid) / [Google Account: Location Sharing](https://support.google.com/accounts/answer/9363497?hl=en&co=GENIE.Platform%3DDesktop)

## 먼저 확인할 조건
실시간 위치 공유는 아무 기기에서나 바로 켜지는 기능이 아닙니다. Google Account 도움말은 이 설정이 기기와 계정에 따라 따로 적용되며, 기본적으로 꺼져 있다고 설명합니다. 그래서 버튼이 보이지 않을 때는 기능 고장보다 계정과 기기 조건부터 확인하는 편이 빠릅니다. [Google Account: Location Sharing](https://support.google.com/accounts/answer/9363497?hl=en&co=GENIE.Platform%3DDesktop)

공유를 시작하려면 아래 조건을 먼저 봐야 합니다.

- Google Account에 로그인되어 있어야 합니다.
- 휴대전화나 태블릿의 `Use location` 설정이 켜져 있어야 합니다.
- 인터넷 연결이 되어 있어야 합니다.
- Google Maps 앱을 Android 기기에서 열어야 합니다.

여기서 `Use location`은 기기가 현재 위치를 읽도록 허용하는 설정입니다. 꺼져 있으면 지도 앱이 내 위치를 찾기 어렵기 때문에, 공유 대상과 시간을 고르기 전에 먼저 확인해야 합니다. [Google Account: Location Sharing](https://support.google.com/accounts/answer/9363497?hl=en&co=GENIE.Platform%3DDesktop)

또 한 가지는 공유받는 사람의 계정입니다. 개별 공유는 상대가 Gmail 계정이어야 하며, Google Maps 도움말은 연락처에 그 사람의 Gmail 주소를 먼저 넣어 두라고 안내합니다. 이름만 저장해 둔 연락처라면 바로 찾지 못할 수 있습니다. [Google Maps: real-time location sharing](https://support.google.com/maps/answer/15437054?hl=en&co=GENIE.Platform%3DAndroid)

## Android에서 공유 시작하기
일반적인 실시간 위치 공유는 Google Maps의 `Location sharing`에서 시작합니다. 공유 시간도 이 단계에서 정합니다. 짧게만 보여 주고 끝낼지, 직접 끌 때까지 유지할지 먼저 고르면 나중에 중단을 잊을 가능성이 줄어듭니다. [Google Maps: real-time location sharing](https://support.google.com/maps/answer/15437054?hl=en&co=GENIE.Platform%3DAndroid)

1. Android 휴대전화나 태블릿에서 `Google Maps`를 엽니다.
2. Google 계정에 로그인되어 있는지 확인합니다.
3. 상대의 Gmail 주소를 Google Contacts에 추가합니다.
4. 프로필 사진이나 이니셜을 탭합니다.
5. `Location sharing`을 열고 `New share`를 선택합니다.
6. 공유할 시간을 고릅니다.
7. 공유할 사람의 프로필을 탭합니다.
8. 연락처 접근을 묻는다면 허용합니다.
9. `Share`를 탭합니다.

이 절차에서 중요한 점은 공유 대상과 계정입니다. Google Maps는 개별 공유에서 수신자가 Gmail 계정이어야 한다고 안내합니다. 따라서 상대가 Google 계정을 쓰지 않는다면 이 방식 대신 링크 공유를 봐야 합니다. [Google Maps: real-time location sharing](https://support.google.com/maps/answer/15437054?hl=en&co=GENIE.Platform%3DAndroid)

### 공유 시간을 고르는 기준
공유 시간은 단순한 옵션처럼 보이지만 실제로는 관리 방식입니다. 일정 시간만 공유하면 약속 장소나 귀가 확인처럼 끝이 정해진 상황에 맞습니다. `Until you turn this off`를 선택하면 직접 멈출 때까지 이어집니다. [Google Maps: real-time location sharing](https://support.google.com/maps/answer/15437054?hl=en&co=GENIE.Platform%3DAndroid)

시간을 정해 두면 공유를 잊어버릴 가능성이 줄어듭니다. 반대로 가족이나 같은 일정의 사람과 계속 공유해야 한다면 직접 중단하는 방식이 더 맞습니다. 공유 목적이 짧은 확인인지, 계속 보는 용도인지에 따라 이 단계에서 선택이 갈립니다.

## 링크로 보내는 방법
상대가 Google Account가 없으면 링크로 공유할 수 있습니다. 이 방식은 특정 사람의 프로필에 붙이는 공유가 아니라, 복사한 링크를 메시지나 메일로 전달하는 방식입니다. Google Maps 도움말은 이 링크를 가진 사람에게 실시간 위치를 최대 24시간까지 보여 줄 수 있다고 안내합니다. [Google Maps: real-time location sharing](https://support.google.com/maps/answer/15437054?hl=en&co=GENIE.Platform%3DAndroid)

1. `Google Maps`를 엽니다.
2. Google 계정에 로그인합니다.
3. 프로필 사진이나 이니셜을 탭합니다.
4. `Location sharing`에서 `New share`를 선택합니다.
5. 링크를 복사하려면 `Copy to clipboard`를 탭합니다.
6. 메일, 문자, 메신저에 붙여 넣어 전달합니다.

링크 공유는 상대가 Gmail 계정이 없어도 된다는 점이 가장 큽니다. 대신 링크가 전달된 순간부터는 그 링크를 가진 사람이 위치를 볼 수 있으므로, 누구에게 보냈는지와 어디에 남았는지 직접 관리해야 합니다. [Google Maps: real-time location sharing](https://support.google.com/maps/answer/15437054?hl=en&co=GENIE.Platform%3DAndroid)

### 개별 공유와 링크 공유 차이
| 구분 | 개별 공유 | 링크 공유 |
|---|---|---|
| 받는 사람 | Gmail 계정이 있는 사람 | Google Account가 없는 사람도 가능 |
| 선택 방식 | 특정 프로필을 고름 | 링크를 복사해 전달 |
| 공유 기간 | 선택한 시간 또는 직접 중단 | 최대 24시간 |
| 관리 기준 | 사람별로 중단 | 링크를 가진 사람 전체 |

두 방식은 비슷해 보여도 관리 단위가 다릅니다. 상대가 구글 계정을 쓰는지, 잠깐만 보여 주면 되는지, 아니면 특정 사람에게만 계속 보여야 하는지에 따라 선택이 달라집니다. [Google Maps: real-time location sharing](https://support.google.com/maps/answer/15437054?hl=en&co=GENIE.Platform%3DAndroid) / [Google Account: Location Sharing](https://support.google.com/accounts/answer/9363497?hl=en&co=GENIE.Platform%3DDesktop)

## 이동 중 경로도 함께 보내기
자동차, 도보, 자전거 길찾기를 시작하면 실시간 위치뿐 아니라 목적지와 예상 도착 시간도 함께 공유할 수 있습니다. 이 기능은 단순히 현재 자리에 있는지를 보여 주는 것보다, 지금 어디로 가는지 알리는 데 더 맞습니다. [Google Maps: real-time location sharing](https://support.google.com/maps/answer/15437054?hl=en&co=GENIE.Platform%3DAndroid)

1. 목적지를 설정합니다.
2. 길안내를 시작합니다.
3. 정보 카드에서 위로 쓸어 올립니다.
4. `Share trip progress`를 탭합니다.
5. 공유할 사람을 고릅니다.
6. `Share`를 탭합니다.

이 방식은 길찾기를 하고 있을 때만 쓸 수 있습니다. 도착하거나 탐색을 멈추면 공유도 끝납니다. 그래서 출발부터 도착까지의 진행 상황만 보여 주면 되는 상황에 적합합니다. [Google Maps: real-time location sharing](https://support.google.com/maps/answer/15437054?hl=en&co=GENIE.Platform%3DAndroid)

### 언제 이 방식을 쓰면 좋을까
`Share trip progress`는 약속 장소로 이동 중이라는 사실을 함께 알릴 때 유용합니다. 목적지와 예상 도착 시간이 함께 보이기 때문에, 단순 위치보다 상황 전달이 분명합니다. 반면 목적지 없이 오래 켜 두는 용도라면 일반 위치 공유가 더 맞습니다. [Google Maps: real-time location sharing](https://support.google.com/maps/answer/15437054?hl=en&co=GENIE.Platform%3DAndroid)

중간에 공유를 끊고 싶다면 정보 카드에서 위로 올린 뒤 `Stop sharing`을 탭합니다. 목적지에 도착하면 자동으로 끝나지만, 도착 전에 멈추고 싶을 때는 이 방법을 써야 합니다.

## 공유를 멈추는 방법
실시간 위치 공유는 시작한 곳에서 끊는 것이 가장 쉽습니다. 사람별로 공유를 멈출 수 있고, 내비게이션 중 공유는 목적지 도착과 함께 종료됩니다. Google Account 도움말은 계정 페이지에서도 사람별로 관리할 수 있다고 설명합니다. [Google Maps: real-time location sharing](https://support.google.com/maps/answer/15437054?hl=en&co=GENIE.Platform%3DAndroid) / [Google Account: Location Sharing](https://support.google.com/accounts/answer/9363497?hl=en&co=GENIE.Platform%3DDesktop)

1. `Google Maps`를 엽니다.
2. 프로필 사진이나 이니셜을 탭합니다.
3. `Location sharing`을 엽니다.
4. 중단할 사람의 프로필을 탭합니다.
5. `Stop`을 탭합니다.

계정 페이지에서 정리하려면 `myaccount.google.com`의 `People & sharing`로 가서 `Location Sharing`을 찾으면 됩니다. 그다음 `Manage Location Sharing`에서 중단할 사람을 선택해 `Stop`을 누르면 됩니다. PC에서는 이처럼 이미 공유 중인 항목을 확인하고 끊는 역할이 중심입니다. [Google Account: Location Sharing](https://support.google.com/accounts/answer/9363497?hl=en&co=GENIE.Platform%3DDesktop)

### 큰 화면에서 관리할 때
휴대전화가 손에 없을 때는 PC에서 확인하는 편이 편할 수 있습니다. 다만 새 공유를 시작하는 기본 절차는 Android 기준으로 안내되어 있으므로, PC에서는 관리와 중단을 중심으로 보면 됩니다. 새로 공유를 시작해야 한다면 다시 Android의 `Location sharing` 절차로 돌아가야 합니다. [Google Account: Location Sharing](https://support.google.com/accounts/answer/9363497?hl=en&co=GENIE.Platform%3DDesktop)

## 공유가 안 될 때 확인할 것
공유가 안 될 때는 먼저 계정과 연락처 조건을 보아야 합니다. Google Maps 도움말은 상대의 Gmail 주소를 연락처에 넣어 두어야 하고, 경우에 따라 연락처 접근 권한을 허용해야 한다고 안내합니다. [Google Maps: real-time location sharing](https://support.google.com/maps/answer/15437054?hl=en&co=GENIE.Platform%3DAndroid)

다음 항목도 함께 확인하면 좋습니다.

- Google Account에 로그인되어 있는지
- `Use location` 설정이 켜져 있는지
- 인터넷 연결이 안정적인지
- 상대가 Gmail 계정인지
- 공유 시간이 이미 끝나지 않았는지

Google Account 도움말은 위치 공유가 기기와 계정별 설정이라고 밝힙니다. 그래서 같은 계정이라도 다른 기기에서는 다시 확인해야 할 수 있습니다. 휴대전화에서만 설정했고 태블릿에서는 보이지 않는 경우가 여기에 해당합니다. [Google Account: Location Sharing](https://support.google.com/accounts/answer/9363497?hl=en&co=GENIE.Platform%3DDesktop)

### 24시간 이후 문제가 있을 때
링크 공유처럼 일정 시간이 정해진 방식은 24시간을 넘기지 못합니다. Google Maps 도움말은 장기 공유가 꼬였을 때 나이 확인을 먼저 보라고 안내하고, 그다음 `Until you turn this off` 방식으로 다시 설정해 보라고 설명합니다. 이후에는 검색창에서 이름, 전화번호, 이메일로 대상을 찾는 방법도 있습니다. [Google Maps: real-time location sharing](https://support.google.com/maps/answer/15437054?hl=en&co=GENIE.Platform%3DAndroid)

이 항목은 단순히 버튼이 안 보일 때보다, 이전 공유가 오래 이어졌는데 정상적으로 관리되지 않을 때 참고하기 좋습니다. 바로 공유가 필요하면 기본 절차부터 다시 시도하고, 오래된 공유 문제일 때만 이 부분을 확인하면 됩니다.

구글 지도 실시간 위치 공유는 대상, 시간, 방식만 구분하면 어렵지 않습니다. Gmail 계정이 있는 사람에게는 개별 공유를, 계정이 없는 사람에게는 링크 공유를, 이동 중에는 경로 공유를 고르면 됩니다. 중단은 같은 메뉴에서 바로 할 수 있으므로, 시작할 때 공유 시간을 함께 정해 두면 관리가 편합니다. [Google Maps: real-time location sharing](https://support.google.com/maps/answer/15437054?hl=en&co=GENIE.Platform%3DAndroid) / [Google Account: Location Sharing](https://support.google.com/accounts/answer/9363497?hl=en&co=GENIE.Platform%3DDesktop)
