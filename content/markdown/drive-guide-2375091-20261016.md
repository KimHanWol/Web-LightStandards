구글 드라이브에서 파일 정리는 폴더를 만들고, 파일을 알맞은 위치로 옮기고, 자주 찾는 항목은 바로가기로 묶어 두는 방식으로 하면 됩니다. 먼저 무엇을 실제 파일로 둘지, 무엇을 바로가기로 둘지 정하면 뒤에서 다시 찾기 쉬워집니다. 폴더 색상과 별표도 함께 쓰면 목록이 길어져도 헷갈림을 줄일 수 있습니다.

정리하다 보면 “이 파일을 옮겨도 되는지”, “여러 곳에서 보이게 하려면 어떻게 하는지”가 자주 걸립니다. Drive는 파일 이동, 사본 만들기, 바로가기 추가를 서로 다르게 다루므로 이 셋을 구분하는 것이 먼저입니다. 공식 도움말은 한 가지 정답만 있는 것이 아니라, 찾기 쉬운 구조를 만들기 위한 여러 방법을 안내합니다. [Google 드라이브에서 파일 정리하기](https://support.google.com/drive/answer/2375091?hl=ko&co=GENIE.Platform%3DDesktop), [Google Drive에서 파일 공유하기](https://support.google.com/drive/answer/2494822?hl=ko&co=GENIE.Platform%3DDesktop)

## 먼저 폴더 구조부터 잡기

Drive 정리는 폴더 이름을 잘 짓는 것에서 시작합니다. 폴더는 같은 주제의 파일을 한곳에 모아 주는 상자라고 보면 됩니다. 파일이 많은데도 찾기 어렵다면, 먼저 “프로젝트”, “연도”, “업무 종류”처럼 스스로 구분할 수 있는 기준부터 세우는 편이 좋습니다.

이때 너무 복잡하게 시작할 필요는 없습니다. 도움말도 간단한 구조로 시작하고 필요할 때 하위 폴더를 늘리라고 안내합니다. 즉, 처음부터 여러 겹으로 쪼개기보다 지금 찾기 쉬운 수준으로 나누는 것이 우선입니다.

### 폴더 만들기

1. 컴퓨터에서 `drive.google.com`을 엽니다.
2. 왼쪽에서 `새로 만들기`를 누르고 `폴더`를 선택합니다.
3. 폴더 이름을 입력합니다.
4. `만들기`를 선택합니다.

이렇게 만든 폴더는 이후 파일을 넣을 기준점이 됩니다. 이름은 짧고 의미 있게 잡는 것이 좋습니다. 날짜나 프로젝트 이름을 함께 넣으면 나중에 비슷한 폴더와 구분하기가 쉽습니다.

### 이름을 정할 때 보아야 할 것

- 같은 종류의 파일인지 바로 알아볼 수 있는가
- 날짜나 프로젝트명으로 순서를 짐작할 수 있는가
- 비슷한 이름의 폴더와 헷갈리지 않는가

이 세 가지가 맞으면 폴더 이름이 길지 않아도 정리 기준으로 쓰기 좋습니다. 이름 규칙은 파일 자체를 바꾸는 작업이 아니라, 다음에 찾는 시간을 줄이기 위한 약속에 가깝습니다.

## 파일을 옮길 때 구분할 것

파일을 정리할 때 가장 많이 쓰는 기능은 이동입니다. 이동은 파일의 위치를 바꾸는 것이고, 바로가기는 원본을 대신 가리키는 연결입니다. 둘은 결과가 다르기 때문에 목적에 따라 달리 써야 합니다.

예를 들어 한 파일을 한 군데에만 두고 싶다면 이동이 맞습니다. 반대로 여러 폴더에서 같은 파일을 쉽게 찾고 싶다면 바로가기가 더 맞을 수 있습니다. 공식 도움말도 “어디에 둘 것인가”와 “어디에서 열 수 있게 할 것인가”를 분리해서 설명합니다.

### 파일이나 폴더를 직접 이동하기

1. `drive.google.com`에서 옮길 파일 또는 폴더를 마우스 오른쪽 버튼으로 클릭합니다.
2. `정리` > `이동`을 선택합니다.
3. 대상 폴더를 고르거나 새 폴더를 만듭니다.
4. `이동`을 선택합니다.

이 방법은 위치를 명확히 바꾸고 싶을 때 씁니다. 파일이 옮겨진 뒤에는 이전 위치에서 보이지 않아야 정상입니다. 만약 파일이 아주 많은 폴더를 옮기는 중이라면, 변경사항이 반영되는 데 시간이 걸릴 수 있습니다.

### 드래그해서 옮기기

1. `drive.google.com`에서 옮길 항목을 잡습니다.
2. 폴더 위로 끌어다 놓습니다.

드래그는 빠르지만, 놓는 위치를 잘 봐야 합니다. 특히 비슷한 폴더가 많을수록 실수하기 쉽습니다. 파일이 실제로 들어갔는지 확인하려면, 옮긴 뒤 폴더를 열어 파일 이름이 보이는지 보면 됩니다.

### 이동할 때 권한이 필요한 이유

파일을 옮기려면 원본 위치와 대상 위치 모두에 대한 이동 권한이 필요합니다. 이 권한이 없으면 파일이 옮겨지지 않고, 경우에 따라 대상 폴더에 바로가기가 생길 수 있습니다. 그래서 공유된 드라이브나 다른 사람이 관리하는 폴더에서는 “왜 안 옮겨지지?”보다 먼저 권한 조건을 살펴봐야 합니다.

즉, 이동이 실패했다고 해서 항상 기능이 없는 것은 아닙니다. 내가 파일을 다룰 수 있는 범위가 충분한지 먼저 확인해야 합니다. 이 차이를 알아두면 바로가기가 생긴 상황도 이해하기 쉽습니다.

## 바로가기와 사본을 구분하기

바로가기는 원본 파일이나 폴더를 참조하는 연결입니다. 원본을 여러 곳에서 빠르게 찾게 해 주지만, 내용 자체를 복제하는 것은 아닙니다. 반면 사본은 실제 파일을 새로 만드는 것입니다.

이 차이가 중요한 이유는 수정 결과가 다르기 때문입니다. 바로가기를 눌러 들어가도 원본이 열립니다. 사본은 별도의 파일이라서 수정해도 원본과 분리됩니다. 따라서 “같은 파일을 여러 곳에서 보이게만 할 것인지”, “내용을 따로 관리할 것인지”를 먼저 정해야 합니다.

### 바로가기 추가하기

1. 바로가기를 만들 파일 또는 폴더를 마우스 오른쪽 버튼으로 클릭합니다.
2. `정리` > `바로가기 추가`를 선택합니다.
3. 바로가기를 둘 위치를 고릅니다.
4. `바로가기 추가`를 선택합니다.

이 방법은 폴더 구조를 복잡하게 만들지 않으면서 자주 쓰는 항목에 접근하고 싶을 때 유용합니다. 특히 여러 프로젝트에서 같은 자료를 참조할 때 원본은 한곳에 두고, 각 프로젝트 폴더에는 바로가기를 둘 수 있습니다.

### 바로가기를 지울 때 주의할 점

바로가기를 삭제해도 원본 파일은 삭제되지 않습니다. 반대로 휴지통을 비우면 바로가기가 완전히 없어집니다. 따라서 바로가기를 지우는 것은 “참조를 제거하는 일”이지 “파일 자체를 지우는 일”과 같지 않습니다.

이 부분을 헷갈리면 중요한 자료를 잃었다고 생각하기 쉽습니다. 실제로는 링크만 지운 경우가 많으니, 원본 위치를 먼저 확인하는 습관이 필요합니다.

## 색상과 별표로 빨리 찾기

폴더 색상은 목록에서 같은 종류를 눈에 띄게 구분하는 데 도움이 됩니다. 색상은 사용 중인 Drive 버전에만 적용되므로, 다른 기기나 다른 버전에서 보는 모양이 완전히 같지는 않을 수 있습니다. 그래서 색상은 보조 수단으로 쓰고, 이름 규칙은 따로 유지하는 편이 좋습니다.

별표는 자주 열어보는 파일이나 폴더를 빠르게 모아 보는 방식입니다. 중요한 자료를 따로 분류해 두고 싶을 때 유용하지만, 별표만으로 폴더 구조가 자동 정리되지는 않습니다. 즉, 별표는 “바로 가는 표식”이고, 폴더는 “보관 위치”입니다.

### 색상 바꾸기와 별표 표시

- 폴더를 마우스 오른쪽 버튼으로 클릭하고 `정리`에서 폴더 색상을 선택합니다.
- 파일이나 폴더를 마우스 오른쪽 버튼으로 클릭하고 `정리` > `별표표시 추가`를 선택합니다.

색상은 같은 성격의 폴더를 묶을 때, 별표는 당장 자주 찾는 항목을 모을 때 쓰면 이해하기 쉽습니다. 두 기능을 같은 용도로 쓰기보다 역할을 나눠 두는 편이 정리 기준이 흔들리지 않습니다.

## 중복 파일을 찾고 정리하기

정리하다 보면 같은 이름의 파일이 여러 개 생기기도 합니다. Drive 도움말은 이름순 정렬과 검색창 사용을 기본 방법으로 안내합니다. 중복을 찾을 때는 먼저 목록 보기에서 이름순으로 보고, 비슷한 이름의 파일이 많은 폴더는 검색으로 좁히는 편이 빠릅니다.

중복을 찾았다고 해서 바로 삭제하면 안 됩니다. 복사본인지, 진짜 같은 자료인지, 혹은 버전이 다른 파일인지 먼저 구분해야 합니다. 특히 작업 기록이 남아야 하는 파일은 이름이 비슷해도 내용이 다를 수 있습니다.

### 중복을 확인하는 순서

1. 목록을 이름순으로 정렬합니다.
2. 비슷한 이름의 파일이 같은 폴더에 있는지 봅니다.
3. 검색창으로 특정 파일명이나 형식을 찾아 봅니다.
4. 휴지통으로 옮기기 전 원본이 맞는지 다시 확인합니다.

실수로 휴지통에 넣은 파일이나 폴더는 복원할 수 있습니다. 다만 복원 가능하다고 해서 바로 삭제해도 되는 것은 아닙니다. 정리 기준이 흔들리지 않으려면, 지우기 전에 무엇이 원본이고 무엇이 중복인지 먼저 판단해야 합니다.

## 공유 폴더에서는 무엇이 달라지나

Drive에서 파일을 정리할 때 공유 상태가 섞여 있으면 더 조심해야 합니다. 폴더에 적용한 액세스 권한은 그 안의 파일에 이어질 수 있기 때문입니다. 그래서 어떤 파일을 어느 사람에게 보여 줄지와, 어떤 폴더에 넣을지를 함께 생각해야 합니다.

예를 들어 특정 파일만 따로 다르게 보여 주고 싶어도, 상위 폴더 권한이 더 강하면 낮은 권한을 임의로 줄일 수 없습니다. 이런 경우에는 액세스가 제한된 하위 폴더를 따로 두는 편이 더 낫습니다. 정리 구조와 공유 구조를 같이 봐야 하는 이유가 여기에 있습니다. 자세한 공유 역할 차이는 [구글 드라이브 공유 권한](https://support.google.com/drive/answer/2494822?hl=ko&co=GENIE.Platform%3DDesktop) 도움말이 기준이 됩니다.

또한 팀에서 바로가기를 쓰면 여러 Drive 안의 자료를 찾기 쉽습니다. 다만 바로가기는 원본을 숨기는 기능이 아니므로, 공유 대상과 접근 범위는 별도로 확인해야 합니다. 파일을 옮겼는데 공유가 달라 보인다면, 이동 자체보다 폴더 권한을 먼저 살펴보는 편이 맞습니다.

정리의 마지막은 “내가 다시 찾을 수 있는가”를 보는 것입니다. 폴더 이름이 보이고, 자주 쓰는 파일은 별표에서 바로 열리고, 여러 위치에서 필요한 자료는 바로가기로 연결된다면 기본 구조는 잘 잡힌 것입니다. 그 다음에야 중복 파일과 색상을 손보는 편이 덜 헷갈립니다.
