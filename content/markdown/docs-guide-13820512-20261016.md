## 줄 번호는 페이지 형식에서만 쓸 수 있습니다
Google Docs의 줄 번호는 문서의 줄 위치를 옆에 표시해 특정 문장을 빠르게 찾고 다른 사람과 같은 줄을 가리키는 데 도움이 됩니다. 다만 이 기능은 **페이지 형식** 문서에서만 사용할 수 있고, **페이지 없음 형식**에서는 표시되지 않습니다. [Google Docs 도움말: 줄 번호 사용하기](https://support.google.com/docs/answer/13820512?hl=ko&co=GENIE.Platform%3DDesktop)

줄 번호를 처음 켤 때는 “어디에 보이게 할지”보다 먼저 “이 문서가 페이지 형식인지”부터 보는 편이 안전합니다. 같은 문서라도 형식이 페이지 없음으로 바뀌면 줄 번호가 사라질 수 있기 때문입니다. 문서 전체를 참조용으로 관리하려는 경우와 줄 단위로 서로 확인해야 하는 경우에 특히 잘 맞습니다.

페이지 형식은 문서를 실제 페이지 단위로 나눠 보이게 해서 줄 번호를 계산할 기준이 생깁니다. 반대로 페이지 없음 형식은 화면 너비에 따라 줄이 다시 흐르기 때문에, 같은 문장도 줄 위치가 달라질 수 있어 번호를 고정해 보여 주기 어렵습니다.

1. 줄 번호가 필요한 문서는 먼저 페이지 형식인지 확인합니다.
2. 페이지 없음으로 되어 있다면 줄 번호를 켜기 전에 형식을 바꿉니다.
3. 공동작업 중이라면 모두가 같은 형식으로 보고 있는지도 함께 확인합니다.

## 줄 번호를 켜는 기본 순서
줄 번호는 메뉴에서 한 번 켜면 문서 전체에 적용되는 기본 상태로 표시됩니다. 가장 먼저 문서를 열고, 상단 메뉴에서 줄 번호 설정을 찾으면 됩니다. 이름이 비슷한 다른 보기 옵션과 섞이지 않도록 경로를 차분히 따라가는 것이 좋습니다.

1. Google Docs에서 문서를 엽니다.
2. 상단 메뉴에서 `도구`를 클릭합니다.
3. `줄 번호`를 선택합니다.
4. 줄 번호 사이드바에서 `줄 번호 표시`를 켭니다.

이렇게 설정하면 줄 번호가 문서 옆에 나타납니다. 기본값은 문서 전체에서 연속으로 증가하는 방식입니다. 따라서 특별한 구간 분리 없이도 전체 흐름을 참조할 수 있습니다. [Google Docs 도움말: 줄 번호 사용하기](https://support.google.com/docs/answer/13820512?hl=ko&co=GENIE.Platform%3DDesktop)

줄 번호를 끄고 싶다면 같은 위치로 돌아가 표시를 해제하면 됩니다. 문서 내용을 지우는 것이 아니라 번호 표시만 바꾸는 것이므로, 본문 자체에는 영향을 주지 않습니다.

## 번호를 다시 시작하는 기준 정하기
문서가 길어지면 전체 문서에서 계속 이어지는 번호보다, 페이지마다 다시 시작하거나 섹션마다 다시 시작하는 방식이 더 읽기 쉬울 때가 있습니다. 줄 번호 메뉴에서는 이 재시작 기준을 고를 수 있습니다. 어떤 기준을 택하느냐에 따라 같은 문서라도 참조 방식이 달라집니다.

재시작 옵션은 다음처럼 생각하면 이해하기 쉽습니다.

- `문서 전체에서 계속`: 문서 전체를 하나의 흐름으로 볼 때 적합합니다.
- `각 페이지에서 다시 시작`: 페이지마다 1번부터 다시 세기 때문에 인쇄본이나 페이지 단위 검토에 맞습니다.
- `각 섹션에서 다시 시작`: 장, 절, 구역처럼 내용 덩어리를 나눠 관리할 때 맞습니다.

설정 방법은 줄 번호 사이드바에서 재시작 기준을 선택한 뒤 적용 대상을 고르는 흐름입니다. 문서 전체에 적용할지, 현재 섹션에만 적용할지 먼저 정해야 합니다. 이때 `섹션`은 문서를 구분해 따로 다룰 수 있게 나눈 구간을 뜻합니다. 줄 번호를 구역별로 다르게 쓰려면 섹션이 필요합니다. [Google Docs 도움말: 줄 번호 사용하기](https://support.google.com/docs/answer/13820512?hl=ko&co=GENIE.Platform%3DDesktop)

재시작을 바꾸면 참조 방식도 함께 바뀝니다. 예를 들어 같은 문장이라도 “12번 줄”이 문서 전체 기준인지, 해당 페이지 기준인지에 따라 다른 위치가 될 수 있습니다. 다른 사람과 함께 문서를 볼 때는 어떤 기준으로 말하는지 먼저 맞춰 두는 편이 좋습니다.

재시작 기준은 문서를 어떻게 읽고 나눌지에 따라 달라집니다. 한 문서 안에서도 앞부분은 연속 번호로 두고, 부록이나 별도 장만 다시 시작하게 하면 긴 문서를 덜 헷갈리게 볼 수 있습니다.

1. 전체 흐름을 하나로 참조할 때는 `문서 전체에서 계속`을 고릅니다.
2. 출력물이나 페이지 단위 검토가 필요하면 `각 페이지에서 다시 시작`이 맞습니다.
3. 장·절처럼 구역마다 따로 확인해야 하면 `각 섹션에서 다시 시작`을 선택합니다.
4. 함께 보는 사람에게는 어떤 기준인지 먼저 알려야 같은 번호를 같은 위치로 이해할 수 있습니다.

## 특정 구역만 줄 번호 보이기
줄 번호는 문서 전체에만 쓰는 것이 아니라 일부 구역에만 보이게 할 수도 있습니다. 다만 문서에 섹션이 없으면 `이 섹션` 같은 적용 대상을 쓸 수 없습니다. 즉, 특정 부분만 따로 다루려면 먼저 섹션을 만들어야 합니다.

1. 커서를 줄 번호를 따로 적용하고 싶은 위치에 둡니다.
2. `삽입`을 클릭합니다.
3. `나누기`를 선택합니다.
4. `섹션 나누기(다음 페이지 또는 연속)`를 넣습니다.
5. `도구`에서 `줄 번호`를 엽니다.
6. `적용 대상`에서 `이 섹션`을 선택하고 줄 번호 표시를 켭니다.

여기서 중요한 점은 `섹션 나누기`가 있어야 구간 단위 설정이 가능하다는 것입니다. 그냥 문단을 비워 두는 것만으로는 다른 섹션이 되지 않습니다. 섹션을 만들었는지 헷갈리면 `보기` 메뉴의 `인쇄 불가 문자 표시`를 켜서 확인할 수 있습니다. 이 기능은 눈에 보이지 않는 문단 나누기, 줄바꿈, 섹션 나누기 같은 표시를 파란색 문자로 보여 줍니다. [Google Docs 도움말: 줄 번호 사용하기](https://support.google.com/docs/answer/13820512?hl=ko&co=GENIE.Platform%3DDesktop), [Google Docs 도움말: 문서 개요, 눈금자, 인쇄 불가 문자 보기](https://support.google.com/docs/answer/6367684?hl=ko&co=GENIE.Platform%3DDesktop)

특정 구역만 번호를 보이게 하면 긴 문서에서 검토 범위를 줄이기 쉽습니다. 예를 들어 초안의 앞부분만 먼저 검토하거나, 부록과 본문을 나눠 다룰 때 참조가 덜 혼란스럽습니다.

여기서 말하는 `섹션`은 문단이 아니라, 문서를 따로 나눠 설정할 수 있는 구간입니다. 그래서 그냥 빈 줄을 넣는다고 되는 것이 아니라, `섹션 나누기`를 넣어야 적용 대상을 좁힐 수 있습니다.

1. 줄 번호를 따로 둘 범위를 먼저 정합니다.
2. 그 앞에서 섹션 나누기를 넣어 문서 구간을 분리합니다.
3. 줄 번호 사이드바에서 `이 섹션`을 선택해 현재 구간에만 적용합니다.
4. 일부만 보이게 한 뒤에는 다른 구역으로 이동해 번호가 끊겨 보이는지 확인하면 설정이 맞는지 바로 알 수 있습니다.

## 번호가 안 보일 때 먼저 볼 점
줄 번호가 보이지 않으면 기능이 고장 난 것처럼 느껴질 수 있지만, 실제로는 적용 조건이 맞지 않는 경우가 많습니다. 가장 먼저 볼 것은 문서 형식입니다. 페이지 없음 형식이라면 줄 번호가 표시되지 않으므로, 문서가 페이지 형식인지 확인해야 합니다.

그다음에는 줄 번호 메뉴에서 `줄 번호 표시`가 켜져 있는지 봅니다. 메뉴에서 설정했더라도 표시가 꺼져 있으면 화면에는 나타나지 않습니다. 또 특정 구역에만 적용하려던 경우라면 해당 섹션이 실제로 만들어졌는지도 확인해야 합니다.

인쇄 불가 문자 표시를 켜 보면 섹션 나누기가 들어갔는지 더 쉽게 알 수 있습니다. 눈에 보이지 않던 구분선이 표시되므로, 왜 적용 대상이 좁아졌는지 파악하는 데 도움이 됩니다. [Google Docs 도움말: 문서 개요, 눈금자, 인쇄 불가 문자 보기](https://support.google.com/docs/answer/6367684?hl=ko&co=GENIE.Platform%3DDesktop)

정리하면, 줄 번호는 단순히 켜는 기능이 아니라 문서 형식과 구간 나누기까지 함께 맞아야 잘 작동합니다. 문서 전체에서 사용할지, 페이지마다 다시 시작할지, 특정 섹션만 따로 볼지 정한 뒤 설정하면 나중에 참조할 때 덜 헷갈립니다.

줄 번호가 안 보일 때는 기능 자체보다 적용 대상이 맞는지부터 보는 편이 빠릅니다. 페이지 형식이 맞는지, 표시가 켜져 있는지, 섹션을 만들었다면 그 섹션이 실제로 분리됐는지를 차례로 확인하면 원인을 좁히기 쉽습니다.

1. 문서 형식이 페이지인지 확인합니다.
2. `도구 > 줄 번호`에서 `줄 번호 표시`가 켜져 있는지 봅니다.
3. 특정 구역만 설정했다면 섹션 나누기가 들어갔는지 확인합니다.
4. 그래도 보이지 않으면 인쇄 불가 문자를 켜서 눈에 안 보이는 구분이 있는지 살펴봅니다.
