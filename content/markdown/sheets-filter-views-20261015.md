구글 스프레드시트에서 데이터를 거를 때는 **필터**와 **필터 보기**를 구분해야 합니다. 필터는 시트에 바로 적용되므로 다른 사람에게도 보일 수 있고, 필터 보기는 내 화면에만 적용해 따로 저장할 수 있습니다. 공유 문서에서 내 조건으로만 보고 싶다면 필터 보기부터 확인하는 편이 안전합니다.

공유된 표를 함께 쓰는 상황에서는 이 차이가 특히 중요합니다. 같은 범위를 보더라도 누구는 전체를 보고, 누구는 일부만 보게 설정할 수 있기 때문입니다. 아래에서 필터와 필터 보기의 차이, 만드는 방법, 수정과 삭제, 그리고 필터가 안 보일 때 점검할 조건까지 차례대로 정리합니다.

## 필터와 필터 보기 차이

구글 스프레드시트의 **필터**는 데이터를 숨기고 정렬하는 일반 기능입니다. 한 번 적용하면 그 범위에 남아 있고, 편집 권한이 있는 사람은 같은 필터를 바꾸거나 없앨 수 있습니다. Google 도움말은 필터가 스프레드시트 접근자에게 보이며, 협업 문서에서 공유되는 상태라고 설명합니다. [Google Sheets: sort and filter](https://support.google.com/docs/answer/3540681?hl=en&co=GENIE.Platform%3DDesktop)

반면 **필터 보기**는 같은 시트라도 내 작업용으로 따로 저장하는 보기입니다. 도움말의 비교 설명에 따르면 필터 보기는 내가 적용한 상태를 따로 보관할 수 있고, 다른 사람의 화면에 그대로 영향을 주지 않습니다. 그래서 팀 문서에서 내 조건만 잠시 바꿔 보고 싶을 때 적합합니다. [Google Sheets: slicers for charts and tables](https://support.google.com/docs/answer/9245556?hl=en&co=GENIE.Platform%3DDesktop)

| 항목 | 필터 | 필터 보기 |
|---|---|---|
| 보이는 범위 | 적용된 시트 범위 전체 | 내 화면 기준으로 저장 가능 |
| 다른 사람 영향 | 있을 수 있음 | 기본적으로 줄어듦 |
| 저장 방식 | 범위에 직접 적용 | 보기로 따로 관리 |
| 적합한 상황 | 공동으로 같은 조건을 볼 때 | 각자 다른 조건으로 볼 때 |

필터 보기는 **같은 표를 보더라도 사람마다 다른 조건이 필요한 경우**에 유리합니다. 예를 들어 거래 내역에서 특정 담당자만 보고 싶거나, 상태값별로 번갈아 확인해야 할 때입니다. 반대로 모두가 같은 기준으로 데이터를 걸러야 한다면 일반 필터가 더 단순합니다.

필터와 필터 보기를 헷갈리는 이유는 둘 다 데이터를 숨기고 정렬할 수 있기 때문입니다. 하지만 **필터는 시트 범위에 직접 적용**되고, **필터 보기와 슬라이서는 개인별로 다르게 보거나 저장하는 방식**이라는 점이 다릅니다. 공유 문서라면 내가 바꾼 조건이 다른 사람에게도 보이는지부터 먼저 구분해야 합니다.

필터는 같은 범위를 보는 사람끼리 조건을 맞춰야 할 때 적합합니다. 반대로 여러 사람이 같은 문서를 보면서 각자 다른 기준으로 확인해야 하면 필터 보기처럼 개인별로 분리된 보기가 더 안전합니다.

## 필터 보기 만드는 방법

필터 보기는 PC에서 시트를 열고 범위를 선택한 뒤 만들 수 있습니다. 문서에 따라 메뉴 위치만 익혀 두면 조작은 단순합니다. 여기서 범위는 필터를 적용할 데이터 묶음이고, 표의 머리글까지 포함해 잡는 경우가 많습니다.

1. 구글 스프레드시트에서 원하는 표가 있는 파일을 엽니다.
2. 필터 보기를 적용할 범위를 선택합니다. 머리글이 있다면 첫 줄까지 포함하는 편이 좋습니다.
3. 상단 메뉴에서 `Data`를 누르고 `Create filter view`를 선택합니다.
4. 범위 위에 생긴 필터 막대에서 조건을 고릅니다.
5. 값으로 거를지, 조건으로 거를지 선택한 뒤 적용합니다.

조건으로 거르는 방법은 데이터 모양에 따라 다릅니다. 도움말에서는 값 목록에서 체크를 해제하는 방식, 특정 조건을 고르는 방식, 직접 수식을 쓰는 방식까지 안내합니다. 일반적인 목록형 데이터라면 값 선택이 가장 쉽고, 규칙이 복잡하면 조건이나 수식을 씁니다. [Google Sheets: sort and filter](https://support.google.com/docs/answer/3540681?hl=en&co=GENIE.Platform%3DDesktop)

필터를 만들 때는 **병합된 셀**, 숨겨진 행·열, 조건부 서식, 데이터 유효성 검사 규칙 때문에 `Create a filter`가 비활성화될 수 있습니다. 이 경우에는 먼저 병합을 해제하고, 숨김 처리된 행·열이 있으면 표시한 뒤 다시 시도합니다. 그래도 안 되면 해당 시트를 복사해 필터가 되는지 확인하는 방법이 있습니다. [Google Sheets: sort and filter](https://support.google.com/docs/answer/3540681?hl=en&co=GENIE.Platform%3DDesktop)

필터 보기를 만들기 전에 범위를 어떻게 잡을지 먼저 정하는 것이 중요합니다. 머리글이 있는 표라면 제목 행까지 포함해야 열 이름으로 조건을 고르기 쉽고, 일부 열만 걸러야 할 때도 같은 범위를 유지해야 나중에 조건이 흐트러지지 않습니다.

1. 표 전체를 드래그해 범위를 선택합니다.
2. 머리글이 있으면 제목 행도 포함했는지 다시 확인합니다.
3. `Data > Create filter view`를 눌러 필터 보기를 만듭니다.
4. 각 열의 필터 아이콘에서 값 또는 조건을 선택합니다.
5. 필요한 경우 정렬까지 함께 적용한 뒤 결과를 확인합니다.

적용 후에는 화면 아래쪽이나 범위 끝에서 남은 행 수를 확인하면 됩니다. 도움말에서도 필터가 걸리면 표시된 행 수가 전체 행 수와 함께 보인다고 안내하므로, 조건이 너무 좁거나 잘못 잡힌 경우를 바로 확인할 수 있습니다. [Google Sheets: sort and filter](https://support.google.com/docs/answer/3540681?hl=en&co=GENIE.Platform%3DDesktop)

## 필터 보기로 나만 따로 보기

필터 보기는 같은 데이터를 두고도 내 작업 조건을 별도로 저장해야 할 때 씁니다. 협업 문서에서 다른 사람이 같은 시트를 열어도 내 필터 보기가 그대로 강제되지 않으므로, 임시 검토에 적합합니다. 도움말의 비교 설명에서도 필터 보기는 저장 가능한 보기, 필터는 공유된 상태로 설명됩니다. [Google Sheets: slicers for charts and tables](https://support.google.com/docs/answer/9245556?hl=en&co=GENIE.Platform%3DDesktop)

필터 보기를 만들 수 있다면, 먼저 어떤 열을 기준으로 볼지 정한 뒤 그 조건을 저장합니다. 이때 같은 데이터 집합을 쓰는 여러 표나 차트가 있으면 적용 범위를 혼동하지 않도록 범위를 맞춰야 합니다. 도움말은 한 열당 한 개의 슬라이서를 쓸 수 있고, 같은 데이터 집합을 쓰는 표와 차트에 적용된다고 안내합니다. [Google Sheets: slicers for charts and tables](https://support.google.com/docs/answer/9245556?hl=en&co=GENIE.Platform%3DDesktop)

필터 보기를 사용할 때는 **내 화면에서만 바뀌는지**를 먼저 확인합니다. 다른 사람도 같은 결과를 봐야 한다면 필터 보기만으로는 부족할 수 있습니다. 이 경우에는 기본 상태로 저장할지, 모두가 같은 보기로 따라가야 하는지 문서 운영 방식부터 정해야 합니다. 도움말은 슬라이서의 선택을 기본값으로 저장할 수 있다고 설명합니다. [Google Sheets: slicers for charts and tables](https://support.google.com/docs/answer/9245556?hl=en&co=GENIE.Platform%3DDesktop)

필터 보기의 핵심은 **같은 파일을 보더라도 내 조건이 다른 사람의 화면을 바꾸지 않는다**는 점입니다. 그래서 공유 문서에서 잠깐 특정 담당자, 특정 상태, 특정 기간만 확인해야 할 때 유용합니다.

다만 필터 보기라고 해서 아무 권한 없이 항상 저장되는 것은 아닙니다. 도움말에 따르면 편집 권한이 없으면 임시 필터 보기만 만들 수 있고, 편집 권한이 있을 때 저장된 보기로 관리할 수 있습니다. 즉, 협업 문서에서 내 조건을 남기고 싶다면 먼저 내 권한이 보기 저장까지 가능한지 확인해야 합니다. [Google Sheets: sort and filter](https://support.google.com/docs/answer/3540681?hl=en&co=GENIE.Platform%3DDesktop)

## 슬라이서가 필요한 경우

슬라이서는 차트, 표, 피벗 테이블을 조건에 따라 걸러 보는 도구입니다. 필터와 비슷해 보이지만, 시트 안에서 따로 조작하는 컨트롤처럼 쓸 수 있다는 점이 다릅니다. 대시보드처럼 표와 차트를 함께 보는 문서에서 특히 유용합니다. [Google Sheets: slicers for charts and tables](https://support.google.com/docs/answer/9245556?hl=en&co=GENIE.Platform%3DDesktop)

슬라이서를 추가하려면 먼저 차트나 피벗 테이블을 선택하고 `Data`에서 `Add a slicer`를 누릅니다. 오른쪽에서 필터할 열을 고른 뒤, 조건 또는 값으로 거릅니다. 같은 열에 대해 여러 개를 저장할 수는 없고, 다른 열을 보려면 슬라이서를 추가로 만들어야 합니다. [Google Sheets: slicers for charts and tables](https://support.google.com/docs/answer/9245556?hl=en&co=GENIE.Platform%3DDesktop)

슬라이서의 선택은 기본값으로 저장하지 않으면 개인적인 상태로 남습니다. 즉, 문서를 닫았다가 다시 열면 보이는 조건이 달라질 수 있습니다. 공유 문서에서 같은 조건을 계속 유지해야 한다면 기본값 저장 여부를 먼저 확인해야 합니다. [Google Sheets: slicers for charts and tables](https://support.google.com/docs/answer/9245556?hl=en&co=GENIE.Platform%3DDesktop)

## 안 보일 때 먼저 볼 항목

필터나 필터 보기가 예상대로 안 뜰 때는 기능 문제보다 문서 상태를 먼저 봐야 합니다. 도움말 기준으로는 병합된 셀, 숨김 행·열, 조건부 서식, 데이터 유효성 검사 규칙이 원인이 될 수 있습니다. 이런 항목이 있으면 먼저 제거하거나 풀어야 필터 기능이 살아납니다. [Google Sheets: sort and filter](https://support.google.com/docs/answer/3540681?hl=en&co=GENIE.Platform%3DDesktop)

확인 순서는 단순하게 잡는 편이 좋습니다.

- 숨겨진 행이나 열이 있는지 확인합니다.
- 병합된 셀이 있는지 확인하고 필요하면 해제합니다.
- 조건부 서식 규칙이 적용됐는지 확인합니다.
- 데이터 유효성 검사 규칙이 있는지 확인합니다.
- 그래도 안 되면 시트를 복사해 다시 시도합니다.

이 순서로 보면 원인이 문서 구조인지, 권한인지 구분하기 쉽습니다. 특히 복사본에서 필터가 되면 원본의 제약 때문에 막힌 것일 수 있습니다. 반대로 복사본에서도 안 되면 범위 선택이나 시트 구조를 다시 살펴야 합니다. [Google Sheets: sort and filter](https://support.google.com/docs/answer/3540681?hl=en&co=GENIE.Platform%3DDesktop)

필터 기능이 안 보일 때는 메뉴 문제보다 시트 구조가 원인인 경우가 많습니다. 특히 병합된 셀이나 숨김 행·열은 범위 인식을 흐리게 만들어 `Create a filter`가 비활성화될 수 있습니다.

확인할 때는 다음처럼 차례대로 보면 좋습니다.

1. 병합된 셀이 있는지 확인합니다.
2. 숨겨진 행이나 열이 있는지 확인합니다.
3. 조건부 서식이 적용돼 있는지 확인합니다.
4. 데이터 유효성 검사 규칙이 있는지 확인합니다.
5. 그래도 안 되면 같은 시트를 복사해 필터가 되는지 봅니다.

복사본에서 필터가 되면 원본의 구조나 권한 제약을 의심할 수 있습니다. 반대로 복사본에서도 안 되면 범위 선택이 잘못됐거나, 필터가 적용되기 어려운 셀 구성이 남아 있는지 다시 확인해야 합니다. [Google Sheets: sort and filter](https://support.google.com/docs/answer/3540681?hl=en&co=GENIE.Platform%3DDesktop)

## 정리와 선택 기준

공유 문서에서 **모두가 같은 조건으로 봐야 하면 필터**, **내가 따로 조건을 저장해 보고 싶으면 필터 보기**가 맞습니다. 차트나 피벗 테이블까지 함께 거를 계획이라면 슬라이서도 고려할 수 있습니다. 핵심은 기능 이름보다, 적용 범위가 개인용인지 공동용인지 먼저 가르는 것입니다.

실무에서는 다음처럼 고르면 됩니다.

1. 내 화면만 바꾸고 싶으면 필터 보기부터 찾습니다.
2. 공동으로 같은 기준을 써야 하면 일반 필터를 씁니다.
3. 표와 차트를 함께 제어해야 하면 슬라이서를 검토합니다.
4. 기능이 안 보이면 병합 셀과 숨김 행·열부터 확인합니다.

이 기준만 잡아도, 같은 스프레드시트 안에서 조건을 잘못 건드려 다른 사람의 화면을 바꾸는 일을 줄일 수 있습니다. 공유 파일일수록 “어디까지 내 설정인지”를 먼저 보는 편이 안전합니다. [Google Sheets: sort and filter](https://support.google.com/docs/answer/3540681?hl=en&co=GENIE.Platform%3DDesktop), [Google Sheets: slicers for charts and tables](https://support.google.com/docs/answer/9245556?hl=en&co=GENIE.Platform%3DDesktop)
