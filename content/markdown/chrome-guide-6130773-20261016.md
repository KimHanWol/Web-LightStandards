Chrome 게스트 모드는 다른 사람의 컴퓨터를 빌려 쓰거나 내 컴퓨터를 잠시 빌려줄 때 사용하는 별도 탐색 환경입니다. 게스트 모드에서 방문한 웹사이트는 Chrome의 로컬 방문 기록에 표시되지 않으며, 모드를 종료하면 방문 기록·쿠키·사이트 데이터가 컴퓨터에서 삭제됩니다. 다만 웹사이트, 네트워크 관리자, 인터넷 서비스 제공업체까지 활동을 숨겨 주는 기능은 아닙니다.

이 글은 컴퓨터용 Chrome의 게스트 모드를 기준으로 설명합니다. Chromebook에서는 게스트 모드를 사용할 수 없고, 관리 설정에 따라 게스트 모드가 보이지 않을 수도 있습니다. 휴대전화 Chrome의 사용법은 이 범위에 포함하지 않습니다.

## 게스트 모드를 쓰면 무엇이 달라지나요?

게스트 모드는 현재 Chrome 프로필의 정보와 분리된 임시 탐색 공간입니다. 여기서 말하는 Chrome 프로필은 방문 기록, 북마크, 설정처럼 한 사용자의 브라우저 정보를 묶어 둔 환경입니다. 게스트 모드에서는 다른 Chrome 프로필의 정보를 찾거나 변경할 수 없으므로, 다른 사람이 내 브라우저 환경을 그대로 열어 보는 일을 피하는 데 사용할 수 있습니다.

게스트 모드를 종료하면 그 세션에서 만든 방문 기록, 쿠키, 사이트 데이터가 삭제됩니다. 쿠키는 웹사이트가 로그인 상태나 기본 설정 등을 유지하기 위해 브라우저에 저장하는 정보입니다. 따라서 게스트 창을 닫은 뒤 같은 사이트의 로그인 상태나 임시 설정이 남아 있지 않은지 걱정되는 상황에 적합합니다. 이 기능의 적용 범위와 삭제 대상은 [Google Chrome 공식 도움말의 게스트 모드 안내](https://support.google.com/chrome/answer/6130773?hl=ko&co=GENIE.Platform%3DDesktop)에서 확인할 수 있습니다.

다만 ‘기록이 남지 않는다’는 말은 컴퓨터 안의 Chrome 기록에 저장되지 않는다는 뜻으로 이해해야 합니다. 방문한 웹사이트, 로그인한 웹사이트, 학교나 회사처럼 네트워크를 운영하는 조직, 인터넷 서비스 제공업체, 검색엔진은 별도로 활동을 파악할 수 있습니다. 게스트 모드는 완전한 익명 접속이나 네트워크 추적 차단 기능이 아닙니다.

## 컴퓨터에서 게스트 모드 여는 순서

게스트 모드는 Chrome의 현재 프로필을 삭제하거나 바꾸는 작업이 아닙니다. 별도 게스트 창을 시작한 뒤 그 창에서 웹을 이용하고, 사용이 끝나면 게스트 모드를 종료하는 흐름입니다.

1. 컴퓨터에서 Chrome을 엽니다.
   
   평소 사용하는 Chrome 창이 이미 열려 있어도 됩니다. 게스트 모드는 현재 프로필의 브라우저 데이터를 지우는 절차가 아니라 별도의 탐색 환경을 여는 절차입니다.

2. 오른쪽 상단에서 프로필을 선택합니다.
   
   프로필 메뉴는 현재 사용 중인 Chrome 프로필과 관련된 선택지를 보여 주는 영역입니다. 여기서 일반적인 새 창이나 다른 프로필이 아니라 게스트 프로필을 찾아야 합니다.

3. `게스트 프로필`을 엽니다.
   
   새 게스트 창이 열리면 그 창에서 필요한 웹사이트를 방문합니다. 일반 프로필의 방문 기록이나 설정을 확인·변경하는 대신, 현재 게스트 세션 안에서만 탐색해야 분리 목적에 맞습니다.

4. 필요한 작업을 마친 뒤 게스트 모드를 종료합니다.
   
   창을 닫는 시점이 세션을 끝내는 시점입니다. 게스트 창을 계속 열어 둔 채 Chrome만 사용하지 않는 방식으로 끝내지 말고, 아래 종료 절차까지 진행합니다.

게스트 프로필이 메뉴에 없다면 먼저 기기 조건을 확인해야 합니다. Chromebook에서는 이 컴퓨터용 게스트 모드를 사용할 수 없습니다. 또 컴퓨터에 관리 대상 사용자가 있고 관리 대상이 아닌 모든 프로필이 잠겨 있다면 게스트 모드를 사용할 수 없다고 Google은 안내합니다. 이 경우 메뉴를 계속 찾기보다 해당 컴퓨터의 관리 설정이나 기기 종류를 확인하는 편이 빠릅니다.

## 사용을 마친 뒤 게스트 모드 종료하기

게스트 모드는 창을 닫아야 탐색 세션이 끝납니다. 종료 전에는 다시 필요한 파일이나 정보를 남겨야 하는지 판단해야 합니다. 게스트 모드에서 방문한 사이트의 기록과 쿠키, 사이트 데이터는 종료 과정에서 삭제되므로 이후 같은 세션을 이어 쓸 수 없습니다.

Windows 및 Linux에서는 게스트 창 오른쪽 상단의 닫기를 선택합니다. Mac에서는 창 왼쪽 상단의 닫기를 선택합니다. 운영체제에 따른 닫기 위치가 다르므로, 창을 닫은 뒤 게스트 창이 더 남아 있지 않은지 살펴봅니다.

다른 방법으로는 오른쪽 상단에서 프로필을 선택한 다음 메뉴의 `게스트 종료`를 선택할 수 있습니다. 이 메뉴를 이용하면 게스트 탐색을 끝내는 동작을 명시적으로 실행할 수 있습니다. 종료 후에는 다음 항목이 컴퓨터에 남지 않는 범위인지 확인합니다.

- 게스트 세션에서 방문한 사이트 기록
- 게스트 세션의 쿠키
- 게스트 세션의 사이트 데이터

이 확인은 ‘모든 흔적이 사라졌는가’를 확인하는 과정이 아닙니다. Chrome의 게스트 세션 데이터가 삭제되었는지와, 웹사이트나 네트워크에 남을 수 있는 활동 기록을 구분하는 과정입니다. 후자의 범위까지 게스트 모드가 삭제하거나 숨겨 주는 것은 아닙니다.

## 게스트 모드에서 로그인해도 괜찮을까요?

게스트 모드라고 해서 민감한 웹사이트에 무조건 안전하게 로그인할 수 있는 것은 아닙니다. Google은 신뢰할 수 있는 기기에서만 민감한 웹사이트에 로그인하라고 안내합니다. 공용 컴퓨터나 다른 사람이 관리하는 컴퓨터에서는 게스트 모드로 Chrome 기록이 남지 않더라도 기기 소유자가 활동이나 위치와 같은 데이터에 접근할 가능성을 고려해야 합니다.

로그인이 꼭 필요한 경우에는 다음 순서로 판단합니다.

1. 지금 사용하는 컴퓨터가 신뢰할 수 있는 기기인지 먼저 판단합니다.
   
   도서관·카페 같은 공용 컴퓨터라면 기기 관리 상태를 알기 어렵습니다. 비밀번호, 결제 정보, 업무 계정처럼 노출될 경우 영향이 큰 정보는 로그인 자체를 미루는 것이 안전한 선택일 수 있습니다.

2. 로그인하면 웹사이트에 어떤 정보가 전달되는지 생각합니다.
   
   게스트 모드는 웹사이트가 사용자의 접속을 보거나 서비스 데이터를 수집하는 일을 막지 않습니다. 로그인한 사이트와 그 사이트가 사용하는 광고·리소스는 별도의 데이터를 처리할 수 있습니다.

3. 작업을 마치면 게스트 창을 닫고 `게스트 종료`까지 진행합니다.
   
   단순히 다른 탭으로 이동하는 것만으로는 게스트 세션이 끝나지 않습니다. 모든 게스트 창이 닫혔는지 확인해야 Chrome에 저장되는 게스트 세션 데이터가 삭제되는 종료 흐름을 마칠 수 있습니다.

검색을 이용할 때도 검색엔진에 추천 검색어가 표시될 수 있습니다. 현재 게스트 탐색 세션의 활동이나 위치를 바탕으로 추천이 달라질 수 있으며, Google 검색에서는 대략적인 위치를 추정할 수 있다고 안내되어 있습니다. 따라서 추천 검색어가 보인다는 이유만으로 게스트 모드가 실패했다고 판단할 필요는 없습니다.

## 게스트 모드와 시크릿 모드 구분하기

게스트 모드와 시크릿 모드는 모두 기기에 남는 탐색 정보를 제한하지만, 출발점이 다릅니다. 게스트 모드는 다른 사람이 사용하는 컴퓨터에서 내 Chrome 프로필 정보와 분리해 탐색하려는 경우에 맞습니다. 시크릿 모드는 내 프로필의 설정과 정보를 계속 이용하면서 비공개 탐색 세션을 시작하려는 경우에 더 가깝습니다.

| 구분 | 게스트 모드 | 시크릿 모드 |
|---|---|---|
| 주된 용도 | 다른 사람의 컴퓨터를 빌려 쓰거나 내 컴퓨터를 빌려줄 때 | 내 정보와 설정을 유지하며 별도 세션으로 탐색할 때 |
| 다른 Chrome 프로필 정보 | 찾거나 변경할 수 없음 | 기존 프로필의 정보와 설정을 계속 확인할 수 있음 |
| 세션 종료 후 | 방문 기록·쿠키·사이트 데이터 삭제 | 사이트 데이터·방문한 사이트 기록을 Chrome이 보관하지 않음 |
| 다운로드한 파일 | 제공된 근거에서 별도 설명 없음 | 삭제할 때까지 기기에 남음 |
| 네트워크·웹사이트 추적 | 막지 않음 | 막지 않음 |

시크릿 모드에서는 사용자가 저장한 북마크와 다운로드한 파일이 종료 후에도 남을 수 있습니다. 반면 게스트 모드의 공식 안내는 게스트 세션 종료 시 방문 기록, 쿠키, 사이트 데이터가 삭제된다고 설명합니다. 따라서 목적이 ‘내 프로필 정보와 분리된 임시 사용’인지, ‘내 브라우저 설정을 유지한 채 기록 저장을 제한하는 것’인지 먼저 정한 뒤 모드를 선택해야 합니다.

시크릿 모드를 열 때는 Chrome 오른쪽 상단의 더보기에서 `새 시크릿 창`을 선택합니다. Windows·Linux·ChromeOS에서는 `Ctrl + Shift + N`, Mac에서는 `⌘ + Shift + N` 단축키를 사용할 수 있습니다. 시크릿 세션은 시크릿 창을 모두 닫아야 끝나므로, 창 하나만 닫고 종료되었다고 판단하지 않아야 합니다. 자세한 차이와 시크릿 창의 저장 범위는 [Google Chrome 공식 시크릿 모드 도움말](https://support.google.com/chrome/answer/95464?hl=ko&co=GENIE.Platform%3DDesktop)에서 확인할 수 있습니다.

## 사용 전후에 판단할 기준

게스트 모드는 다음과 같은 상황에서 목적이 분명합니다. 다른 사용자에게 내 컴퓨터를 잠시 빌려주면서 내 Chrome 프로필을 열지 못하게 하고 싶을 때, 또는 내가 다른 사람의 컴퓨터에서 내 브라우저 정보와 분리해 웹을 이용하고 싶을 때입니다. 도서관이나 카페처럼 여러 사람이 사용하는 컴퓨터에서 Chrome의 로컬 기록을 남기고 싶지 않을 때도 사용할 수 있습니다.

반대로 로그인 정보나 결제 정보처럼 보호 수준을 높여야 하는 작업이라면 게스트 모드만 믿고 진행하지 않아야 합니다. 게스트 모드는 로컬 Chrome 기록과 세션 데이터를 다루는 기능이지, 기기 관리자·웹사이트·네트워크 운영자·인터넷 서비스 제공업체로부터 사용자를 숨기는 기능이 아니기 때문입니다.

사용을 마친 뒤에는 다음 세 가지만 순서대로 확인하면 됩니다. 게스트 창에서 하던 작업을 끝냈는지 확인하고, 오른쪽 상단의 `게스트 종료` 또는 운영체제에 맞는 닫기로 세션을 끝냅니다. 마지막으로 일반 Chrome 프로필 창이 열려 있지 않은지 살펴봅니다. 이 과정을 지키면 게스트 모드의 적용 범위와 종료 시 삭제되는 데이터를 혼동하지 않고 사용할 수 있습니다.
