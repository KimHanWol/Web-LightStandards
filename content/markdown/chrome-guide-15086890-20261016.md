## 먼저 알아둘 핵심
Chrome의 Google 렌즈로 검색은 웹페이지를 보다가 화면 속 이미지나 일부 내용을 바로 검색하는 기능입니다. 셔츠 사진에서 구매처를 찾거나 동물 사진에서 종류를 알아보는 식으로 쓸 수 있습니다. 다만 데스크톱 Chrome에서 쓰는 기능이고, 기본 검색엔진을 Google로 두어야 동작하는 경우가 있습니다. [Chrome의 Google 렌즈로 검색](https://support.google.com/chrome/answer/15086890?hl=ko&co=GENIE.Platform%3DDesktop), [Chrome에서 웹 검색](https://support.google.com/chrome/answer/95440?hl=ko&co=GENIE.Platform%3DDesktop)

이 글은 PC에서 Chrome을 쓰는 경우를 기준으로 설명합니다. 모바일 Chrome의 화면이나 메뉴는 다를 수 있으니, 같은 이름의 기능이 보이지 않아도 서로 섞어서 보지 않는 편이 좋습니다.

## 페이지에서 렌즈 여는 방법
가장 기본 흐름은 웹페이지를 연 뒤 Google 렌즈를 여는 것입니다. Chrome 도움말에는 오른쪽 상단의 더보기에서 `Google 렌즈로 이 탭 검색`을 선택하거나, 페이지를 마우스 오른쪽 버튼으로 클릭해서 같은 항목을 고를 수 있다고 안내합니다. [Chrome의 Google 렌즈로 검색](https://support.google.com/chrome/answer/15086890?hl=ko&co=GENIE.Platform%3DDesktop)

1. 컴퓨터에서 Chrome을 엽니다.
2. 검색하고 싶은 내용이 있는 웹사이트로 이동합니다.
3. 오른쪽 상단의 더보기에서 `Google 렌즈로 이 탭 검색`을 선택합니다.
4. 또는 페이지 안의 빈 곳을 마우스 오른쪽 버튼으로 클릭해 같은 항목을 선택합니다.
5. 오른쪽 측면 패널에 검색 결과가 뜨면 내용을 읽어봅니다.

이 흐름에서 중요한 점은 페이지를 그냥 보는 것과 렌즈로 검색하는 것이 다르다는 점입니다. 일반 검색은 주소창에 단어를 넣는 방식이고, 렌즈는 지금 보고 있는 페이지의 내용 자체를 함께 보냅니다. 그래서 이미지나 화면 일부처럼 설명하기 어려운 대상을 찾을 때 더 맞습니다.

### 주소 표시줄에서 시작하는 경우
Chrome 도움말에는 주소 표시줄에서 `이 페이지에 대해 Google에 질문하기`를 선택하는 방법도 나옵니다. 같은 페이지를 바탕으로 질문을 시작할 수 있지만, 일부 안내는 기본 검색엔진이 Google이어야 하고, 페이지 URL 기반 추천을 받으려면 검색 및 탐색 기능 개선을 켜야 한다고 설명합니다. [Chrome에서 웹 검색](https://support.google.com/chrome/answer/95440?hl=ko&co=GENIE.Platform%3DDesktop)

이 경로는 렌즈를 바로 누르는 방법과 달리, 주소창의 추천 항목에서 시작할 수 있다는 점이 다릅니다. 보이는 메뉴가 이쪽으로 더 자연스럽다면 주소창에서 먼저 살펴보면 됩니다. 다만 도움말에 나온 조건이 맞지 않으면 추천이 보이지 않을 수 있습니다.

## 무엇을 선택해서 검색하는지
Google 렌즈는 페이지 전체만 보는 것이 아니라, 필요한 부분을 골라서 검색할 수도 있습니다. 도움말에는 웹페이지에서 텍스트를 클릭하거나 강조 표시하고, 페이지의 아무 곳이나 드래그해 선택할 수 있다고 나옵니다. 선택한 부분은 Google 검색으로 전송되고, 질문을 이어서 넣으면 AI 모드로 이동합니다. [Chrome의 Google 렌즈로 검색](https://support.google.com/chrome/answer/15086890?hl=ko&co=GENIE.Platform%3DDesktop)

여기서 `강조 표시`는 글자나 영역을 눈에 띄게 선택한 상태를 뜻합니다. 긴 문장 전체를 다 옮기기보다, 비교하고 싶은 단어·문장·그림 주변만 고르는 데 도움이 됩니다. 선택한 범위가 좁을수록 검색 의도도 분명해집니다.

### 텍스트를 고를 때
텍스트를 선택하면 문맥을 함께 바탕으로 질문할 수 있습니다. 예를 들어 생소한 용어, 문장 속 대상, 페이지 안에서만 설명이 부족한 부분을 따로 물어볼 때 유용합니다. Chrome 도움말에는 선택한 뒤 후속 질문을 입력하면 AI 모드로 넘어간다고 적혀 있습니다. [Chrome의 Google 렌즈로 검색](https://support.google.com/chrome/answer/15086890?hl=ko&co=GENIE.Platform%3DDesktop)

이 기능을 쓸 때는 “무엇이 궁금한지”를 먼저 정하고 선택 범위를 그에 맞춰 줄이는 편이 좋습니다. 문장 전체를 무작정 붙잡기보다, 대상이 되는 표현을 정확히 고르면 결과도 덜 흔들립니다.

### 이미지를 고를 때
이미지에서는 사진 속 대상 자체를 검색할 수 있습니다. 도움말 예시처럼 셔츠 이미지를 골라 구매처를 찾거나, 동물 사진을 선택해 어떤 동물인지 확인하는 식입니다. 이미지 안의 객체가 중심이므로, 화면 캡처보다 실제 사물 사진에서 쓸 일이 더 많습니다. [Chrome의 Google 렌즈로 검색](https://support.google.com/chrome/answer/15086890?hl=ko&co=GENIE.Platform%3DDesktop)

이미지 외부의 빈 곳을 마우스 오른쪽 버튼으로 클릭해도 `Google 렌즈로 검색`을 선택할 수 있습니다. 이때는 페이지 전체를 기준으로 보면서 찾는 방식이라, 특정 그림 하나를 꼭 집지 않아도 됩니다. 필요한 대상이 무엇인지에 따라 선택 범위가 달라집니다.

## 결과를 보고 닫는 기준
렌즈로 검색하면 결과는 측면 패널에 표시됩니다. 도움말에는 새 탭에서 열고 싶다면 검색 결과를 선택하면 된다고 되어 있습니다. 패널을 닫는 방법도 따로 있어서, 페이지의 아무 곳이나 다시 선택하거나 `Esc` 키를 누르거나, 패널의 닫기 버튼을 누를 수 있습니다. [Chrome의 Google 렌즈로 검색](https://support.google.com/chrome/answer/15086890?hl=ko&co=GENIE.Platform%3DDesktop)

검색 결과가 나왔다고 바로 끝내지 말고, 먼저 현재 페이지의 내용과 맞는지 봐야 합니다. 렌즈는 비슷해 보이는 항목도 함께 보여 줄 수 있으니, 제목만 보지 말고 결과의 설명과 출처를 같이 읽어보는 편이 안전합니다. 결과를 새 탭으로 여는 기능은 더 자세히 비교해야 할 때 쓰면 됩니다.

### 결과가 맞는지 판단하는 법
- 찾고 싶은 대상과 결과의 설명이 실제로 연결되는지 봅니다.
- 이미지라면 같은 모양·색·형태가 이어지는지 확인합니다.
- 텍스트라면 선택한 문장과 결과의 주제가 같은지 비교합니다.
- 같은 검색어라도 결과가 여러 개면, 페이지 내용과 가장 가까운 항목부터 엽니다.

이렇게 보면 렌즈 결과를 그냥 답으로 받는 것이 아니라, 현재 페이지에서 무엇을 근거로 찾았는지 직접 확인하게 됩니다. 처음 보는 항목은 여러 결과를 열어보며 범위를 좁히는 쪽이 낫습니다.

## 안 보일 때 먼저 확인할 것
렌즈 메뉴가 보이지 않으면 먼저 기본 검색엔진을 확인해야 합니다. Chrome 도움말은 Google을 기본 검색엔진으로 설정하라고 적고 있습니다. 또 일부 기능은 아직 모든 사용자에게 바로 보이지 않을 수 있고, AI 모드는 Chrome에 로그인해야 하며 일부 도구는 점진적으로 제공된다고 안내합니다. [Chrome에서 웹 검색](https://support.google.com/chrome/answer/95440?hl=ko&co=GENIE.Platform%3DDesktop)

즉, 메뉴가 안 뜬다고 곧바로 기능이 없는 것은 아닙니다. 먼저 Google이 기본 검색엔진인지 보고, 현재 Chrome이 데스크톱인지 확인한 뒤 다시 시도해 보면 됩니다. 주소 표시줄 추천이 안 나오면 로그인 상태나 기능 제공 범위도 함께 살펴보는 편이 좋습니다.

### 데이터와 기록을 볼 때
렌즈로 웹페이지를 검색하면 페이지의 스크린샷과 페이지 데이터가 Google에 전송됩니다. 도움말에는 특정 쿼리를 처리하기 위한 임시 저장소 이상의 데이터는 저장하지 않으며, 페이지와 이미지는 학습에 사용되지 않는다고 설명합니다. 선택한 부분은 Google 검색에 전송됩니다. 검색 활동을 관리하거나 삭제하려면 `내 Google 활동`으로 이동하라고 안내합니다. [Chrome의 Google 렌즈로 검색](https://support.google.com/chrome/answer/15086890?hl=ko&co=GENIE.Platform%3DDesktop)

이 부분은 기능을 쓰기 전에 알아둘 조건입니다. 화면 일부를 선택해 검색하는 만큼, 어떤 데이터가 전송되는지 알고 써야 합니다. 개인 정보나 민감한 화면을 다루는 경우에는 선택 범위를 줄이고, 필요 없으면 검색 활동 관리 화면에서 기록을 확인하는 편이 좋습니다.

## 실제로 기억할 순서
처음 쓸 때는 복잡하게 생각할 필요가 없습니다. Chrome에서 페이지를 열고, 렌즈를 실행한 뒤, 필요한 부분만 선택해서 결과를 보고 닫으면 됩니다. 기본 검색엔진이 Google인지, 데스크톱 Chrome인지, 측면 패널이 열렸는지만 확인하면 대부분의 흐름은 따라갈 수 있습니다. [Chrome의 Google 렌즈로 검색](https://support.google.com/chrome/answer/15086890?hl=ko&co=GENIE.Platform%3DDesktop), [Chrome에서 웹 검색](https://support.google.com/chrome/answer/95440?hl=ko&co=GENIE.Platform%3DDesktop)

정리하면 이 기능은 “페이지를 읽다가 바로 근거를 찾고 싶을 때” 쓰기 좋습니다. 텍스트를 먼저 찾을지, 이미지를 먼저 찾을지, 아니면 페이지 전체에 질문할지에 따라 시작 버튼만 달라집니다.
