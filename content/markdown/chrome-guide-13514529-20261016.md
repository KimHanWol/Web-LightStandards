휴대전화나 태블릿의 Chrome에서는 웹사이트를 모바일 화면으로 열지, 데스크톱 화면으로 요청할지 기본값으로 정할 수 있습니다. 화면 크기와 기기 메모리에 따라 Chrome이 자동으로 선택하게 하거나, 모든 사이트에 모바일 또는 데스크톱 버전을 요청하는 방식입니다. 특정 사이트만 예외로 지정하는 것도 가능합니다.

이 글은 Android 휴대기기에서 Chrome의 데스크톱 사이트 설정을 관리하는 방법을 다룹니다. PC Chrome의 사이트 설정이나 카메라·마이크 같은 권한 설정은 대상이 아니므로 서로 섞어 보지 않습니다.

## 데스크톱 모드 설정부터 구분하기

Chrome에서 말하는 데스크톱 사이트는 웹페이지에 데스크톱용 화면을 요청하는 기능입니다. 휴대기기 화면에 PC용 사이트가 표시되도록 요청하는 것이므로, 사이트 자체가 휴대기기에서 제공하지 않는 기능까지 새로 만들어 주는 설정은 아닙니다.

기본값은 세 가지로 나뉩니다. **기본 뷰**는 화면 크기와 기기의 RAM에 따라 Chrome이 모바일 또는 데스크톱 버전을 선택합니다. **모바일 사이트**는 항상 모바일 버전을 요청하고, **데스크톱 사이트**는 항상 데스크톱 버전을 요청합니다. 현재 사용 목적에 맞는 범위를 먼저 정하면 설정을 바꾼 뒤 결과를 판단하기 쉽습니다.

| 설정 | Chrome의 동작 | 이런 경우에 맞습니다 |
|---|---|---|
| 기본 뷰 | 화면 크기와 RAM을 보고 자동 선택 | 사이트마다 적절한 화면을 자동으로 쓰고 싶을 때 |
| 모바일 사이트 | 모바일 버전을 항상 요청 | 작은 화면에 맞춘 화면을 우선할 때 |
| 데스크톱 사이트 | 데스크톱 버전을 항상 요청 | PC용 메뉴나 넓은 화면 구성이 필요할 때 |

데스크톱 모드가 필요한 사이트가 일부뿐이라면 전체 기본값을 바꾸기보다 해당 사이트만 예외로 지정하는 편이 관리하기 쉽습니다. 전체 기본값은 방문하는 모든 사이트에 영향을 주지만, 예외 설정은 특정 URL에만 다른 뷰를 적용하기 때문입니다.

## Android에서 기본 뷰 바꾸는 순서

먼저 Chrome의 사이트 설정에서 모든 웹사이트에 적용할 기본 뷰를 선택합니다. 설정을 바꾼 뒤 이미 열려 있던 페이지에는 이전 화면이 남을 수 있으므로, 마지막에 페이지를 새로고침해 변경 결과를 확인해야 합니다. Google의 [휴대기기에서 데스크톱 모드 설정 관리하기](https://support.google.com/chrome/answer/13514529?hl=ko&co=GENIE.Platform%3DDesktop)에도 Android의 기본 설정 경로와 각 뷰의 의미가 안내되어 있습니다.

1. Android 휴대전화나 태블릿에서 Chrome을 엽니다.
2. 주소 표시줄 오른쪽의 `더보기`를 탭합니다.
3. `설정`을 탭합니다.
4. `고급`에서 `사이트 설정`을 엽니다.
5. `데스크톱 사이트`를 선택합니다.
6. `기본 뷰`, `모바일 사이트`, `데스크톱 사이트` 중 원하는 항목을 탭합니다.
7. 웹페이지로 돌아가 페이지를 새로고침합니다.

여기서 선택할 기준은 화면이 예쁘게 보이는지보다 필요한 작업이 완료되는지입니다. PC용 화면에서만 보이는 메뉴나 넓은 표가 필요하다면 데스크톱 사이트를 시도할 수 있습니다. 반대로 읽기나 간단한 입력이 목적이고 화면이 좁다면 모바일 사이트가 더 맞을 수 있습니다. 사이트마다 화면 구성이 다르므로 한 설정이 모든 웹사이트에서 같은 결과를 보장하지는 않습니다.

설정이 제대로 적용되었는지는 페이지가 다시 열린 뒤 확인합니다. 모바일용 화면이 계속 보이는지, 데스크톱용 메뉴나 배치가 나타나는지처럼 실제 페이지 구성을 비교하면 됩니다. 단순히 설정 화면에서 항목을 선택한 것만으로 적용을 끝내지 말고, 현재 페이지를 새로고침한 뒤 판단해야 합니다.

## 특정 사이트만 데스크톱으로 열기

전체 웹사이트는 모바일 화면으로 보면서 한 사이트만 데스크톱 화면으로 사용하려면 사이트 예외를 추가합니다. 예외는 기본 뷰와 다른 설정을 특정 사이트에 적용하는 방식입니다. 업무 사이트처럼 PC 화면이 필요한 곳만 바꾸고, 나머지 웹사이트의 화면은 그대로 유지하고 싶을 때 적합합니다.

1. Chrome에서 `더보기`를 탭합니다.
2. `설정`을 열고 `고급`의 `사이트 설정`으로 이동합니다.
3. `데스크톱 사이트`를 선택합니다.
4. `사이트 예외 추가`를 탭합니다.
5. 데스크톱 사이트로 열 사이트의 URL을 입력합니다.
6. 예외 목록에 입력한 사이트가 들어갔는지 확인합니다.
7. 해당 사이트로 돌아가 페이지를 새로고침합니다.

예외를 추가할 때는 다른 사이트의 주소를 잘못 입력하지 않았는지 살펴봅니다. 예외는 입력한 사이트에 적용되는 설정이므로, 의도한 사이트와 주소가 다르면 변경 결과도 달라질 수 있습니다. 예외를 적용한 뒤에는 해당 사이트의 화면만 데스크톱 형태로 바뀌는지 확인하고, 다른 웹사이트까지 함께 바뀌었다면 전체 기본값을 잘못 변경했는지 다시 봅니다.

현재 방문 중인 사이트에서 바로 데스크톱 뷰를 요청하는 방법도 있습니다. Chrome에서 `더보기`를 탭한 뒤 `데스크톱 사이트`를 선택하면 됩니다. 이 방식으로 바꾼 사이트는 예외 목록에 추가할 수 있으므로, 자주 방문할 때마다 같은 작업을 반복하고 싶지 않다면 설정의 예외 목록에서 관리합니다.

## 기본 설정과 사이트별 설정의 우선순위

기본 설정은 여러 웹사이트에 공통으로 적용되는 기준이고, 사이트별 설정은 특정 사이트에만 적용되는 예외입니다. 따라서 특정 사이트에서 수동으로 데스크톱 뷰를 선택했는데 전체 기본값과 다르게 보인다면, 그 사이트에 저장된 예외 설정이 있는지 먼저 살펴보는 것이 좋습니다.

예를 들어 기본값을 모바일 사이트로 정했더라도 특정 사이트에 데스크톱 사이트 예외가 있으면 해당 사이트는 데스크톱 뷰를 요청할 수 있습니다. 반대로 기본값을 데스크톱 사이트로 바꿔도 특정 사이트의 설정이나 사이트 동작에 따라 원하는 화면이 바로 나타나지 않을 수 있습니다. 이때는 기본값과 현재 사이트의 수동 설정을 따로 확인해야 합니다.

설정 변경 후 확인할 항목은 다음과 같습니다.

- 전체 웹사이트의 기본값을 바꾼 것인지, 현재 사이트만 바꾼 것인지
- `데스크톱 사이트`가 요청 상태로 선택되어 있는지
- 변경한 뒤 페이지를 새로고침했는지
- 예외 목록에 해당 사이트 주소가 들어 있는지
- 데스크톱 화면에서 필요한 메뉴나 기능이 실제로 나타나는지

이 구분을 해 두면 모든 사이트의 화면이 갑자기 달라졌을 때 원인을 찾기 쉽습니다. 전체 기본값을 바꾼 것이라면 기본 뷰를 다시 선택하고, 한 사이트만 다르다면 그 사이트의 예외 설정을 조정하면 됩니다.

## 데스크톱 화면이 표시되지 않을 때

`데스크톱 사이트`를 선택했는데도 모바일 화면이 계속 보인다면 먼저 현재 페이지의 `더보기` 메뉴를 엽니다. `데스크톱 사이트`가 데스크톱 뷰 요청 상태로 선택되어 있는지 확인합니다. 선택이 바뀌었다면 페이지를 새로고침해 새 요청이 반영되도록 합니다.

Chrome의 자동 선택인 `기본 뷰`를 사용하는 경우에는 기기의 RAM 조건도 영향을 줄 수 있습니다. 도움말에 따르면 데스크톱 사이트 자동 선택에는 8GB RAM이 필요하며, 메모리가 부족한 기기는 기본적으로 모바일 사이트로 설정됩니다. 따라서 자동 선택을 사용하면서 모바일 화면이 나오는 경우에는 설정이 고장 났다고 단정하기보다, 자동 선택 조건과 현재 기기의 메모리 범위를 함께 봐야 합니다.

다음 순서로 확인하면 원인을 좁힐 수 있습니다.

1. 현재 사이트의 `더보기` 메뉴에서 `데스크톱 사이트`를 직접 선택합니다.
2. 페이지를 새로고침해 변경된 화면을 요청합니다.
3. `설정`의 `사이트 설정`에서 전체 기본값을 확인합니다.
4. `데스크톱 사이트`의 예외 목록에 해당 사이트가 있는지 살펴봅니다.
5. 자동 선택을 사용 중이라면 기기의 RAM 조건 때문에 모바일 뷰가 선택된 것은 아닌지 판단합니다.

이 과정을 거친 뒤에도 사이트가 모바일 화면을 보여 줄 수 있습니다. 데스크톱 사이트 설정은 Chrome이 사이트에 데스크톱 버전을 요청하는 기능이지, 웹사이트가 제공하지 않는 화면을 강제로 생성하는 기능은 아니기 때문입니다. 따라서 설정과 새로고침이 모두 확인되었다면 사이트 자체의 화면 제공 방식도 고려해야 합니다. 자료에서 확인되지 않은 브라우저 버전별 메뉴나 기기별 지원 여부는 임의로 단정하지 않는 것이 안전합니다.

## 사이트 권한 설정과 혼동하지 않기

데스크톱 모드는 사이트가 모바일 또는 데스크톱용 페이지를 요청하는 설정입니다. 카메라, 마이크, 위치, 알림처럼 사이트가 기기 기능을 사용하는 권한과는 다른 항목입니다. 데스크톱 화면으로 바꿨다고 해서 사이트에 카메라나 마이크 권한이 자동으로 허용되는 것은 아닙니다.

사이트 권한은 별도로 허용하거나 차단할 수 있으며, 특정 사이트의 설정을 바꾸면 그 사이트에는 기본 설정 대신 별도로 적용된 값이 사용됩니다. 권한을 바꾸는 작업이 필요하다면 [Chrome 사이트 설정 권한 변경하기](https://support.google.com/chrome/answer/114662?hl=ko&co=GENIE.Platform%3DDesktop)의 안내를 기준으로 확인합니다.

따라서 화면 모양이 문제라면 `사이트 설정`의 `데스크톱 사이트`를 보고, 카메라·마이크·위치 등의 사용 여부가 문제라면 해당 권한 항목을 따로 봅니다. 두 설정을 한꺼번에 바꾸면 어떤 변경이 문제를 해결했는지 판단하기 어려워지므로, 필요한 항목만 순서대로 조정하는 편이 좋습니다.

## 상황별로 설정을 고르는 기준

모든 웹사이트를 PC 화면으로 보고 싶다면 기본값을 `데스크톱 사이트`로 바꿉니다. 다만 휴대기기 화면에서는 글자와 메뉴가 작게 보일 수 있으므로, 실제로 자주 쓰는 작업이 데스크톱 화면을 필요로 하는지 먼저 생각합니다.

대부분의 사이트는 모바일 화면으로 사용하고 특정 사이트만 PC 화면이 필요하다면 기본값은 `모바일 사이트` 또는 `기본 뷰`로 두고 해당 사이트를 예외로 추가합니다. 이렇게 하면 다른 사이트의 화면까지 불필요하게 바뀌지 않습니다.

어떤 화면이 적절한지 Chrome이 고르게 하고 싶다면 `기본 뷰`를 선택합니다. 이 설정은 화면 크기와 기기의 RAM을 기준으로 모바일 또는 데스크톱 버전을 선택하므로, 기기 조건에 따라 결과가 달라질 수 있습니다. 자동 선택 결과가 원하는 화면과 다르면 현재 사이트에서 데스크톱 뷰를 수동으로 요청하고 새로고침합니다.

마지막으로 설정을 바꾼 뒤에는 실제로 필요한 작업이 가능한지 확인합니다. 데스크톱 메뉴가 보이는지, 페이지의 표나 입력 영역이 제대로 표시되는지, 모바일 화면이 필요한 다른 사이트에는 변화가 없는지를 차례로 보면 됩니다. 원하는 사이트만 바뀌었다면 예외 설정이 목적에 맞게 적용된 것입니다.
