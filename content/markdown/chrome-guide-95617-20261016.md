## 먼저 주소창 아이콘을 봅니다

크롬에서 사이트 연결이 안전한지 확인할 때는 웹페이지 주소 왼쪽의 보안 상태 기호부터 봅니다. 이 아이콘이 Chrome이 그 사이트와 어떤 연결을 맺었는지 알려 주며, 안전한지 아닌지 판단하는 첫 기준이 됩니다. [사이트 연결이 안전한지 확인](https://support.google.com/chrome/answer/95617?hl=ko&co=GENIE.Platform%3DDesktop)

사이트 주소를 열었다고 해서 모두 같은 상태는 아닙니다. Chrome은 연결 방식이 달라지면 아이콘도 바꾸고, 필요하면 경고도 보여 줍니다. 그래서 “페이지가 열렸는가”보다 “주소창에 무엇이 표시되는가”를 먼저 확인하는 편이 좋습니다.

### 아이콘이 말하는 뜻

- **기본값(안전함)**: 사이트와 안전한 비공개 연결을 사용하고 있다는 뜻입니다.
- **정보 또는 안전하지 않음**: 비공개 연결을 사용하지 않는 상태입니다.
- **안전하지 않음 또는 위험함**: 개인정보 입력을 피해야 하는 상태입니다.

Chrome 도움말은 안전한 사이트라도 주소창의 사이트 이름을 다시 보고, 실제로 올바른 사이트인지 확인하라고 안내합니다. 연결이 안전해 보여도 주소가 비슷한 가짜 사이트를 혼동할 수 있기 때문입니다. [사이트 연결이 안전한지 확인](https://support.google.com/chrome/answer/95617?hl=ko&co=GENIE.Platform%3DDesktop)

## 안전함과 안전하지 않음을 구분합니다

보안 상태 기호는 단순한 장식이 아닙니다. 사이트가 정보를 어떻게 주고받는지, 그리고 그 과정에서 다른 사람이 볼 가능성이 있는지 알려 줍니다. 기본값(안전함)은 전송되는 정보가 비공개라는 뜻이고, 정보 또는 안전하지 않음은 비공개 연결이 없다는 뜻입니다.

이 차이는 실제로 입력할 정보를 정할 때 중요합니다. 로그인, 결제, 연락처처럼 민감한 정보를 넣기 전에는 주소창 상태를 먼저 보고, 상태가 좋지 않으면 입력을 멈추는 편이 안전합니다. Chrome 도움말은 안전하지 않음 또는 위험함 상태에서는 개인정보를 입력하지 말라고 설명합니다. [사이트 연결이 안전한지 확인](https://support.google.com/chrome/answer/95617?hl=ko&co=GENIE.Platform%3DDesktop)

### 위험함 경고가 더 강한 이유

빨간색 경고 화면이 전체 페이지로 뜨는 경우는 Google 세이프 브라우징이 안전하지 않다고 신고한 사이트일 수 있습니다. 이런 경우는 단순히 연결 방식만의 문제가 아니라, 사용자의 개인 정보와 보안을 위협할 가능성까지 포함합니다. 그래서 Chrome은 가능하면 사용을 멈추라고 안내합니다. [사이트 연결이 안전한지 확인](https://support.google.com/chrome/answer/95617?hl=ko&co=GENIE.Platform%3DDesktop)

같은 “안전하지 않음”이라도 의미가 조금 다릅니다. 정보 또는 안전하지 않음은 연결 방식의 문제를 먼저 보게 하고, 위험함은 사이트 자체의 위험 가능성까지 함께 보게 합니다. 독자는 둘을 같은 수준으로 보지 말고, 더 강한 경고일수록 더 조심해야 합니다.

## 경고가 뜨면 무엇부터 확인할지

사이트에 문제가 보일 때는 화면을 닫기 전에 원인을 먼저 나눠 보는 것이 좋습니다. Chrome 도움말은 “연결이 비공개로 설정되어 있지 않습니다.” 오류가 전체 페이지로 표시되면 사이트, 네트워크 또는 기기에 문제가 있을 수 있다고 설명합니다. [Chrome의 연결 및 로드 오류 해결 도움말](https://support.google.com/chrome/answer/95617?hl=ko&co=GENIE.Platform%3DDesktop)

1. **주소창 아이콘을 먼저 확인합니다.**
   아이콘이 정보 또는 안전하지 않음인지, 안전하지 않음 또는 위험함인지 구분합니다. 같은 경고처럼 보여도 대응이 달라집니다.

2. **올바른 사이트인지 주소를 다시 봅니다.**
   Chrome은 주소 표시줄의 사이트 이름을 확인하라고 안내합니다. 비슷한 철자나 낯선 도메인이 보이면 바로 입력을 멈추는 것이 좋습니다.

3. **개인정보 입력이 필요한 작업인지 생각합니다.**
   비밀번호, 결제 정보, 주민등록번호처럼 되돌리기 어려운 정보라면 경고가 있는 상태에서 진행하지 않는 편이 안전합니다.

4. **전체 페이지 오류인지, 단순 아이콘 변화인지 구분합니다.**
   아이콘만 바뀐 경우와 전체 경고 화면이 뜬 경우는 의미가 다릅니다. 후자는 사이트나 기기 문제까지 의심해야 합니다.

이 순서로 보면 막연히 “위험해 보인다”에서 멈추지 않고, 어떤 수준의 문제인지 구분할 수 있습니다. 그러면 사이트를 계속 쓸지, 다른 경로를 찾을지 판단하기 쉬워집니다.

## 항상 보안 연결 사용을 켜 둘 때

Chrome의 **항상 보안 연결 사용**은 사이트가 HTTPS를 지원하지 않으면 경고를 먼저 보여 주는 설정입니다. HTTPS는 웹 주소에서 보안 연결을 뜻하는 방식이며, 이 설정을 켜면 Chrome이 가능한 경우 HTTPS로 업그레이드하려고 시도합니다. [Chrome 안전 및 보안 관리하기](https://support.google.com/chrome/answer/10468685?hl=ko&co=GENIE.Platform%3DDesktop)

이 설정은 모든 사이트를 무조건 막는 기능이 아닙니다. 지원하지 않는 사이트를 방문하기 전에 알려 주는 역할이 더 큽니다. 그래서 평소에 안전한 연결 여부를 자주 확인하고 싶다면 도움이 됩니다.

### 공개 사이트와 비공개 사이트 경고를 나눠 볼 수 있습니다

도움말에는 공개 사이트만 경고하는 방식과, 공개 사이트와 비공개 사이트 모두에 대해 경고하는 방식이 나옵니다. 여기서 비공개 사이트는 회사 인트라넷 같은 내부 사이트를 뜻합니다. 사용 환경에 따라 내부 사이트가 자주 막히는지 확인하고, 맞는 경고 수준을 고르면 됩니다. [Chrome 안전 및 보안 관리하기](https://support.google.com/chrome/answer/10468685?hl=ko&co=GENIE.Platform%3DDesktop)

1. Chrome에서 오른쪽 상단 **더보기**를 엽니다.
2. **설정**으로 들어갑니다.
3. 왼쪽에서 **개인 정보 보호 및 보안**을 누릅니다.
4. **보안**을 선택합니다.
5. **항상 보안 연결 사용**을 켭니다.
6. 공개 사이트만 경고할지, 공개·비공개 사이트 모두 경고할지 정합니다.

켜고 나면 HTTPS를 사용하지 않는 사이트를 열 때 주소창에 “안전하지 않음” 경고가 표시될 수 있습니다. 이때는 사이트가 보안 연결을 지원하는지, 아니면 사용을 멈춰야 하는지 판단하면 됩니다.

## 인증서와 기기 상태도 함께 봅니다

사이트가 안전한지 확인할 때 연결만 보는 것으로 끝나지 않을 수도 있습니다. Chrome은 웹사이트 인증서를 사용해 HTTPS 연결을 인증하고 보호하며, 기기에 저장된 인증서를 참고하기도 합니다. 즉, 사이트 문제처럼 보여도 실제로는 기기 인증서나 브라우저 설정이 원인일 수 있습니다. [Chrome 안전 및 보안 관리하기](https://support.google.com/chrome/answer/10468685?hl=ko&co=GENIE.Platform%3DDesktop)

기기에서 인증서를 직접 검토하려면 Chrome의 보안 설정에서 **인증서 관리**로 들어갑니다. 이 항목은 일반적인 사이트 확인보다 조금 더 깊은 점검이 필요할 때만 봐도 충분합니다. 보통은 주소창 아이콘과 경고 문구만으로도 판단할 수 있고, 인증서 관리는 반복적으로 문제가 생길 때 확인하는 보조 수단에 가깝습니다. [사이트 연결이 안전한지 확인](https://support.google.com/chrome/answer/95617?hl=ko&co=GENIE.Platform%3DDesktop)

안전한 연결 여부를 볼 때는 “주소창 아이콘 확인 → 사이트 이름 확인 → 개인정보 입력 여부 판단” 순서로 생각하면 됩니다. 경고가 있는데도 진행해야 하는지부터 고민하면 판단이 흐려집니다. 먼저 상태를 읽고, 그다음에 행동을 정하는 편이 훨씬 단순합니다.

## 확인 뒤에 남기는 판단 기준

사이트 연결이 안전한지 확인한 뒤에는 두 가지만 기억하면 됩니다. 연결이 **기본값(안전함)** 이면 대체로 비공개 연결을 사용하고 있다는 뜻이고, **안전하지 않음** 또는 **위험함** 이면 입력과 진행을 멈추는 쪽이 맞습니다.

- 주소창 왼쪽 아이콘을 먼저 봅니다.
- 사이트 이름이 맞는지 다시 확인합니다.
- 개인정보 입력이 필요한 화면이면 경고 상태에서 진행하지 않습니다.
- 전체 경고 화면이 뜨면 사이트, 네트워크, 기기 문제를 함께 의심합니다.
- 자주 확인해야 한다면 **항상 보안 연결 사용**을 켭니다.

이렇게 보면 크롬의 보안 표시를 “무서운 경고”로만 보지 않고, 지금 안전하게 들어가도 되는지 판단하는 신호로 읽을 수 있습니다. 결국 중요한 것은 아이콘 자체가 아니라, 그 아이콘을 보고 다음 행동을 정하는 일입니다.
