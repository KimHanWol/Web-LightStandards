구글 포토에서 사진 편집은 웹과 앱 모두에서 할 수 있지만, 일부 기능은 환경에 따라 보이지 않을 수 있습니다. 이 글은 PC의 `photos.google.com` 기준으로 자르기, 회전, 필터, 조정 도구, 저장과 되돌리기를 차례대로 정리합니다. [Google Photos: edit photos](https://support.google.com/photos/answer/6128850?hl=en&co=GENIE.Platform%3DDesktop)

편집한 내용은 저장 후 사진에 적용되며, 백업이 켜져 있으면 Google Photos 계정과 동기화될 수 있습니다. 다만 모바일 웹에서는 사용할 수 없는 기능이 있고, 웹에서 찾지 못하면 앱에서 확인해야 하는 항목도 있습니다. [Google Photos: edit photos](https://support.google.com/photos/answer/6128850?hl=en&co=GENIE.Platform%3DDesktop)

## PC에서 편집을 여는 방법

구글 포토 편집은 먼저 사진을 연 뒤 편집 도구를 여는 흐름으로 시작합니다. 웹에서는 `photos.google.com`에 들어가 사진을 열고, 상단의 `Edit`를 선택합니다. 그다음 자르기, 필터, 조정, 도구 같은 항목으로 나뉘어 작업합니다. [Google Photos: edit photos](https://support.google.com/photos/answer/6128850?hl=en&co=GENIE.Platform%3DDesktop)

1. `photos.google.com`에 접속합니다.
2. 편집할 사진을 엽니다.
3. 상단의 `Edit`를 클릭합니다.
4. 필요한 편집 항목을 고릅니다.
5. 작업이 끝나면 `Save`를 누릅니다.

이 순서는 공통 시작점입니다. 사진을 먼저 열어야만 자르기나 회전 같은 개별 도구가 나타나며, 저장을 눌러야 변경 내용이 반영됩니다. 저장하지 않으면 편집 내용이 남지 않을 수 있으니 마지막 단계까지 이어서 확인하는 편이 좋습니다. [Google Photos: edit photos](https://support.google.com/photos/answer/6128850?hl=en&co=GENIE.Platform%3DDesktop)

### 웹과 앱에서 차이가 나는 점

같은 구글 포토라도 모든 편집 기능이 같은 위치에 보이지는 않습니다. 공식 도움말은 모바일 기기에서는 Google Photos 앱을 쓰라고 안내하고, 모바일 웹에서는 일부 기능을 찾지 못할 수 있다고 설명합니다. 따라서 PC 웹에서 보이지 않는 기능은 앱에서 다시 확인해야 합니다. [Google Photos: edit photos](https://support.google.com/photos/answer/6128850?hl=en&co=GENIE.Platform%3DDesktop)

또 하나 확인할 점은 기기 조건입니다. 도움말에는 일부 편집 기능과 도구에 대해 기기 RAM이 최소 4GB여야 한다는 안내가 있습니다. 이 조건은 기능 사용 가능 여부에 영향을 줄 수 있으므로, 편집 도구가 보이지 않을 때는 사진 문제만이 아니라 기기 조건도 함께 살펴봐야 합니다. [Google Photos: edit photos](https://support.google.com/photos/answer/6128850?hl=en&co=GENIE.Platform%3DDesktop)

## 자르기와 회전은 이렇게 합니다

자르기는 사진의 테두리를 잘라 구도를 바꾸는 작업이고, 회전은 사진의 방향을 돌려 세우는 작업입니다. 두 기능은 사진 자체를 크게 바꾸지 않으면서 화면의 중심과 비율을 정리할 때 먼저 쓰기 좋습니다. [Google Photos: edit photos](https://support.google.com/photos/answer/6128850?hl=en&co=GENIE.Platform%3DDesktop)

1. 사진을 연 뒤 `Edit`를 클릭합니다.
2. `Crop & rotate`를 선택합니다.
3. 자르려면 가장자리를 끌어 원하는 범위를 맞춥니다.
4. 방향을 바꾸려면 상단의 `Rotate`를 클릭합니다.
5. 결과를 확인한 뒤 `Save`를 누릅니다.

편집 중에는 사진을 길게 눌러 원본과 비교할 수 있습니다. 이 비교는 바뀐 부분이 너무 과한지 확인하는 데 유용합니다. 특히 자르기 후에는 피사체가 잘리지 않았는지, 회전 후에는 수평선이나 인물 방향이 자연스러운지 함께 보는 편이 좋습니다. [Google Photos: edit photos](https://support.google.com/photos/answer/6128850?hl=en&co=GENIE.Platform%3DDesktop)

### 저장과 원본 되돌리기

구글 포토의 편집은 저장 후 사진에 적용되지만, 나중에 되돌릴 수 있습니다. 도움말은 자르기나 다른 편집 효과를 적용해도 언제든지 취소할 수 있다고 안내합니다. 즉, 저장이 편집의 종료를 의미하더라도 원본을 완전히 잃는 것은 아닙니다. [Google Photos: edit photos](https://support.google.com/photos/answer/6128850?hl=en&co=GENIE.Platform%3DDesktop)

도구마다 되돌리는 방식은 조금 다릅니다. 자르기와 회전은 편집 화면에서 다시 조정할 수 있고, 효과형 편집은 해당 항목을 다시 선택하거나 `Revert`로 되돌리는 흐름이 안내됩니다. 변경이 마음에 들지 않으면 저장 전에 다시 확인하고, 이미 저장했다면 해당 기능의 되돌리기 동작을 찾아야 합니다. [Google Photos: edit photos](https://support.google.com/photos/answer/6128850?hl=en&co=GENIE.Platform%3DDesktop)

## 필터와 조정 도구의 차이

필터는 사진 전체의 분위기를 한 번에 바꾸는 방식이고, 조정 도구는 밝기나 색감처럼 세부 값을 손보는 방식입니다. 같은 사진이라도 원하는 결과가 다르면 접근이 달라집니다. 분위기 변화가 목적이면 필터부터, 노출이나 색 균형이 목적이면 조정 도구부터 보는 편이 좋습니다. [Google Photos: edit photos](https://support.google.com/photos/answer/6128850?hl=en&co=GENIE.Platform%3DDesktop)

### 필터를 적용하는 방법

필터는 간단하게 톤을 바꿔 보고 싶을 때 적합합니다. 웹에서는 사진을 연 뒤 `Edit`에서 `Filters`를 선택하고, 원하는 필터를 고른 뒤 강도를 조절합니다. 적용 뒤에는 `Save`를 눌러 마무리합니다. [Google Photos: edit photos](https://support.google.com/photos/answer/6128850?hl=en&co=GENIE.Platform%3DDesktop)

1. 사진을 연 뒤 `Edit`를 클릭합니다.
2. `Filters`를 선택합니다.
3. 원하는 필터를 고릅니다.
4. 필요하면 강도를 조절합니다.
5. `Save`를 눌러 저장합니다.

필터는 한 번에 분위기를 바꾸지만, 사진마다 사용할 수 있는 선택지가 다를 수 있습니다. 도움말에는 필터나 도구의 종류가 사진 유형에 따라 달라진다고 되어 있습니다. 따라서 목록에 없는 필터가 버그라고 단정하기보다, 그 사진에서 지원되지 않는 경우인지 먼저 살펴봐야 합니다. [Google Photos: edit photos](https://support.google.com/photos/answer/6128850?hl=en&co=GENIE.Platform%3DDesktop)

### 조정 도구로 세부값 바꾸기

조정 도구는 밝기, 대비, 색감처럼 눈에 바로 보이는 요소를 세밀하게 바꾸는 데 씁니다. 웹에서는 `Edit` 다음 `Adjust`를 선택하고, 원하는 항목을 골라 다이얼을 움직입니다. 작업이 끝나면 `Save`를 누릅니다. [Google Photos: edit photos](https://support.google.com/photos/answer/6128850?hl=en&co=GENIE.Platform%3DDesktop)

자주 보게 되는 항목은 `Brightness`, `Contrast`, `Saturation`, `Warmth` 같은 값입니다. 밝기는 전체 화면의 밝고 어두운 정도를, 대비는 톤 차이를, 채도는 색의 진함을, 따뜻함은 색온도를 다룹니다. 용어가 낯설어도 각 항목이 사진의 어느 부분에 영향을 주는지만 알면, 편집 순서를 잡는 데 큰 도움이 됩니다. [Google Photos: edit photos](https://support.google.com/photos/answer/6128850?hl=en&co=GENIE.Platform%3DDesktop)

도구 목록에는 `Highlights`, `Shadows`, `White point`, `Black point`, `Tint`, `Vignette`, `HDR effect`처럼 더 세분된 항목도 있습니다. 하지만 사진마다 제공 범위가 같지는 않습니다. 따라서 처음부터 모든 항목을 다 쓰기보다, 노출과 색감에 직접 영향을 주는 값부터 건드리고 결과를 본 뒤 필요한 항목만 더하는 편이 안전합니다. [Google Photos: edit photos](https://support.google.com/photos/answer/6128850?hl=en&co=GENIE.Platform%3DDesktop)

### 인물·배경 도구는 조건을 봐야 합니다

구글 포토의 도구에는 인물 사진에 맞는 기능도 있습니다. 예를 들어 `Portrait light`는 인물 조명 조정, `Blur`는 배경 흐림, `Color pop`은 배경을 덜 강조하고 피사체 색을 남기는 방식입니다. 이런 도구는 사진 종류에 따라 표시 여부가 달라질 수 있습니다. [Google Photos: edit photos](https://support.google.com/photos/answer/6128850?hl=en&co=GENIE.Platform%3DDesktop)

즉, 같은 편집 화면이 보이더라도 모든 사진에 모든 도구가 열리는 것은 아닙니다. 인물 사진이 아닌데 인물 전용 도구를 찾거나, 반대로 지원되지 않는 사진에서 특정 도구가 안 보인다면 사진 유형에 따른 제한일 수 있습니다. 이런 경우에는 다른 도구로 대체하거나, 앱에서 다시 확인하는 흐름이 맞습니다. [Google Photos: edit photos](https://support.google.com/photos/answer/6128850?hl=en&co=GENIE.Platform%3DDesktop)

## 편집 후 결과를 확인하는 법

저장했다고 끝내기보다, 원본과 비교해 편집이 적절한지 확인하는 과정이 필요합니다. 구글 포토는 편집 중 사진을 눌러 원본과 비교하게 해 주며, 저장 후에도 되돌릴 수 있는 편집이 많습니다. 따라서 결과 확인은 편집의 일부로 보는 편이 좋습니다. [Google Photos: edit photos](https://support.google.com/photos/answer/6128850?hl=en&co=GENIE.Platform%3DDesktop)

확인할 때는 아래 순서가 실용적입니다.

- 피사체가 잘리지 않았는지 봅니다.
- 수평선이나 얼굴 방향이 어색하지 않은지 봅니다.
- 밝은 부분과 어두운 부분의 차이가 지나치지 않은지 봅니다.
- 필터가 원래 색감을 지나치게 바꾸지 않았는지 봅니다.
- 저장 후 다시 열었을 때 원하는 모습이 유지되는지 봅니다.

이 확인은 사진의 목적에 따라 기준이 달라집니다. 문서성 사진이라면 잘림과 선명도가 더 중요하고, 인물 사진이라면 색감과 배경 흐림이 더 중요합니다. 같은 편집이라도 용도에 따라 적정 수준이 다르므로, 저장 전에 한 번 더 비교하는 습관이 편집 실패를 줄입니다. [Google Photos: edit photos](https://support.google.com/photos/answer/6128850?hl=en&co=GENIE.Platform%3DDesktop)

## 저장한 사진을 다시 내려받는 경우

편집한 뒤 파일을 기기에 따로 보관해야 한다면 다운로드를 사용할 수 있습니다. 구글 포토 도움말은 컴퓨터에서 사진이나 동영상을 선택한 뒤 `More`에서 `Download`를 누르면 로컬 복사본을 만들 수 있다고 안내합니다. 즉, 웹에서 편집한 뒤에도 로컬 파일이 필요하면 별도로 내려받아 보관할 수 있습니다. [Google Photos: download edited photos](https://support.google.com/photos/answer/7652919?hl=en&co=GENIE.Platform%3DDesktop)

다만 다운로드한 파일은 운영체제에 따라 파일 자체의 시간 정보가 새로 붙을 수 있습니다. 도움말은 파일 세부 정보에서 메타데이터를 확인할 수 있다고 설명합니다. 따라서 원본의 날짜와 다운로드 후 파일의 표시 시간이 다르더라도, 파일 내용과 메타데이터를 구분해 보는 편이 맞습니다. [Google Photos: download edited photos](https://support.google.com/photos/answer/7652919?hl=en&co=GENIE.Platform%3DDesktop)

파일을 다시 받아야 하는 상황은 보통 두 가지입니다. 다른 기기에서 편집본을 써야 하거나, 클라우드와 별개로 로컬 사본이 필요할 때입니다. 이때는 편집본인지 원본인지 헷갈리지 않도록 저장 후 상태를 한 번 열어 보고, 내려받은 뒤에는 파일 정보도 함께 확인하는 흐름이 안전합니다. [Google Photos: download edited photos](https://support.google.com/photos/answer/7652919?hl=en&co=GENIE.Platform%3DDesktop)

## 막힐 때 먼저 볼 점

편집 기능이 안 보인다고 바로 오류로 볼 필요는 없습니다. 공식 도움말에는 모바일 웹에서 일부 기능이 없을 수 있고, 웹에서 못 찾으면 앱을 사용해 보라고 되어 있습니다. 브라우저 환경이 아니라 앱 문제일 수도 있으니, 같은 사진을 다른 환경에서 다시 열어 보는 방식이 먼저입니다. [Google Photos: edit photos](https://support.google.com/photos/answer/6128850?hl=en&co=GENIE.Platform%3DDesktop)

또 하나는 사진 종류입니다. 도구 옵션은 사진 유형에 따라 달라질 수 있습니다. 인물 사진, 풍경 사진, 지원 범위가 제한된 사진은 보이는 항목이 다를 수 있으므로, 목록이 다르다고 해서 사용 방법이 틀렸다고 단정하면 안 됩니다. 먼저 사진을 바꾸지 말고, 다른 장치나 앱에서 같은 편집 항목이 보이는지 확인하는 편이 좋습니다. [Google Photos: edit photos](https://support.google.com/photos/answer/6128850?hl=en&co=GENIE.Platform%3DDesktop)

마지막으로, 편집 후 적용 방식도 확인해야 합니다. 저장은 변경 반영의 기준이지만, 저장 전과 후의 상태를 비교하는 습관이 있어야 과한 편집을 줄일 수 있습니다. 원본 비교, 저장, 필요 시 되돌리기라는 순서를 기억하면 구글 포토 사진 편집의 대부분은 안정적으로 처리할 수 있습니다. [Google Photos: edit photos](https://support.google.com/photos/answer/6128850?hl=en&co=GENIE.Platform%3DDesktop)
